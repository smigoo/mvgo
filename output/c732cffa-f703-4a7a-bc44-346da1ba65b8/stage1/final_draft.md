## 一、解决的问题

### 1.1 视觉保真与布局还原

**问题：主题切换彻底失效，影响面达 70% 组件。**
部分组件的深色 / 浅色主题切换后视觉无变化，用户切换主题「看起来完全一样」。
**解决：** 定位到 LESS mixin 变量不覆盖同名变量的语义陷阱与运行期注入链不可靠，完成根因治理，主题切换恢复生效。

**问题：五类「视觉出错但门禁检测不到」的布局塌陷。**
产物存在明显视觉错误、但质量门禁全部放行，问题直接流入交付环节。其中代表性三类为：模块比例失调、内容被截断、网格塌成一列。
**解决：** 逐类补齐判据并根治，从「事后人工发现」转为「生成即拦截」。

**问题：视觉分析耗时过长，拖慢整条生成链路。**
主力视觉模型单次调用耗时 218 秒，接近超时上限，多次触发降级。
**解决：** 治理推理模式与参数形态后，单次调用降至 104 秒（降幅约 52%），阶段成功率显著提升。

### 1.2 生成性能与稳定性（09-29 ~ 09-30）

**问题：模型「推理模式」从未真正关闭，生成严重变慢。**
配置层已声明关闭推理，但运行时透传断点导致参数未送达模型，代码生成每个分块耗时 40 ~ 190 秒；更严重的是推理烧光输出预算后会返回空内容，单次失败白等 3 ~ 7 分钟并触发重试。
**解决：** 修复配置透传断点，推理真正关闭。分块耗时大幅下降，空内容重试基本消失。

**问题：生产环境部分接口报 500 / 404，工作台多类请求线上不可用。**
工作台分组、会话、任务等接口线上不可用（如 `workbench/groups` 返回 500、任务快照文件返回 404），影响工作台任务列表、会话加载与产物文件查看。
**解决：** 定位为生产网关路由缺失，一次性补齐 20 条后端专属路由，相关接口全部恢复。

**问题：工作台任务操作全部报 401，用户无法干预运行中的任务。**
任务卡片的取消、暂停、恢复、进度轮询四条操作链路在生产环境一律 401，用户既无法中止跑偏的任务，也无法暂停释放模型额度。
**解决：** 定位为前端请求未携带鉴权凭证（原生请求未走统一客户端），统一改为带凭证的请求通道，取消 / 暂停 / 恢复 / 进度轮询四条链路全部恢复正常。

### 1.3 安全与鉴权加固

**问题：后端接口缺乏统一鉴权，存在越权访问风险。**
部分控制器长期无鉴权校验，未登录请求可直接触达业务逻辑。
**解决：** 双端 API 全面挂锁，未登录请求一律 401；同时对门户校验增加短 TTL 缓存（SHA-256 摘要 + 5 分钟），在安全性不降级的前提下消除每次请求重复校验的开销。

**问题：模型配置存在全局 / 部署级兜底，可能串用他人模型与凭据。**
用户未配置模型时，会静默回落到部署共享的模型与密钥，导致额度串用、问题难定位，也违背「模型每用户独有」的原则。
**解决：** 全链路拔除部署级与全局级模型兜底（覆盖配置解析、13 个模块），未配置模型直接引导用户前往「设置 - 模型配置」，彻底实现用户级隔离。

### 1.4 质量门禁与内容盲区

**问题：门禁只拦「多写」，不拦「该写的没写」。**
产物漏掉设计稿中的文字（如空标题、丢失小标题）时，原有校验天然放行，属于内容盲区。
**解决：** 新增文本覆盖率门禁，按真值中文串覆盖比例分档处置，补齐「缺内容」盲区；上线前对全语料真机产物做离线抽样审计，确认零误伤。

**问题：规范升级后历史产物不达标。**
微码规范更新后，存量生成结果与新规范存在偏差，人工逐条比对成本高、易漏。
**解决：** 对齐最新版规范，实现「生成即合规 + 生成后自动检查 + AI 自动修复」三段闭环，存量偏差由自动修复收敛。

## 二、迭代的新功能

### 2.1 工作台模式与面板选择

- **工作台模式上线：** 面向任务全生命周期的管理工作台，内置任务实时监控面板，入口按钮与 TEST 角标完成视觉升级，并附后台管理页
- **右侧面板能力：** 实时预览、快捷键操作、AI 对话式组件修改，形成「查看 - 调整 - 迭代」的闭环
- **主题系统：** 深色模式一键切换，边栏与弹窗同步适配；分组体验优化
- **面板选择：** 生成时可选浅色 / 深色面板，所选面板如实落到组件产物（不再被模板默认值覆盖）

### 2.2 质量与协作能力

- **质量评分体系：** 组件生成后自动评分，管理员可查看评分详情，质量问题可量化、可追踪
- **公共组件池：** 支持跨项目共享与权限管控，减少重复建设
- **mc-check 自动检查 + AI 修复：** 生成即按最新规范，检查发现问题后自动修复

### 2.3 管理功能

- **管理后台三页面上线：** 用户管理、数据分析、系统日志
- **公告管理：** 新增公告发布与展示能力
- **使用统计导出：** 用量数据可导出，便于成本核算

### 2.4 模型治理

- 重试链路、工作流链全面接入用户自己的模型池，避免用错模型
- 慢模型提示优化：明确归因「模型自身问题」，与平台问题区分，用户可据此决定是否切换更快模型
