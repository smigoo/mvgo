# 水球图（LiquidFill）识别指南

## 问题背景

AI 容易将水球图误识别为 `progress-circle`（进度环形图），导致图表类型错误。

## 水球图的关键特征

### 视觉特征

1. **波浪效果**：
   - 内部有明显的波浪形液体动画
   - 波浪线通常是正弦或余弦曲线
   - 液体表面会有起伏的波动效果

2. **填充效果**：
   - 容器内部有液体填充
   - 填充高度表示百分比或进度
   - 液体颜色通常为蓝色、青色或其他主题色

3. **容器形状**：
   - 通常是圆形容器
   - 可能是其他形状（水滴形、矩形等）
   - 容器边缘清晰可见

4. **数值显示**：
   - 中心或顶部显示百分比数值
   - 如：60%、75%
   - 数值通常较大且醒目

### 与进度环形图的区别

| 特征 | 水球图 (liquidFill) | 进度环形图 (progress-circle) |
|------|---------------------|------------------------------|
| 填充方式 | 液体波浪填充 | 环形进度条 |
| 动画效果 | 波浪起伏 | 进度增长 |
| 视觉重点 | 液体高度 | 环形轨道 |
| 容器 | 实心容器 | 空心圆环 |

## Figma 节点命名规范

正确的命名方式：
- `@echarts/水球图`
- `@echarts/liquidFill`
- 节点名称包含"水球"、"液体"等关键词

## 识别流程

1. **检查节点名称**：
   - 如果包含 `@echarts/水球图`，直接识别为 liquidFill
   - 如果包含"水球"、"液体填充"等关键词，考虑为 liquidFill

2. **分析视觉特征**：
   - 是否有波浪形的液体效果？
   - 容器内部是否有填充区域？
   - 填充高度是否表示进度？

3. **排除其他类型**：
   - 如果只有环形进度条，没有液体效果 → progress-circle
   - 如果是纯圆形仪表盘，有刻度 → gauge

## 输出格式

当识别到水球图时，应输出：

```json
{
  "chartType": "liquidFill",
  "chartName": "水球图",
  "features": {
    "hasWave": true,
    "hasLiquid": true,
    "containerShape": "circle",
    "valueDisplay": "center"
  }
}
```

## 示例场景

### 正确识别为水球图

- 圆形容器，内部有蓝色液体，液体表面有波浪
- 显示"65%"，液体高度约占容器的65%
- 节点名称：`@echarts/水球图`

### 错误识别（应避免）

- 将带有波浪效果的水球图误认为 progress-circle
- 将水滴形状的水球图误认为其他图表
- 忽略节点名称中的"水球"关键词

## 注意事项

1. **优先级**：节点命名 > 视觉特征 > 上下文推断
2. **水球图是特殊图表**：需要 echarts-liquidfill 插件支持
3. **默认配置**：水球图通常配置为单波浪、居中数值显示
4. **颜色**：常用蓝色系，但可以是任何颜色

## 代码示例

```javascript

      formatter: '{a}\n{b}%',

      color: '#fff'

    outline: {
      show: true,
      borderDistance: 4,
      itemStyle: {
        borderWidth: 2,
        borderColor: '#2E93fA'
      }
    }
  }]
}
```
