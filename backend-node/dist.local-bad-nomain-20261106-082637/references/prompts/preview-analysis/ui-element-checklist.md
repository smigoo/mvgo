# UI 元素识别清单

在分析设计稿时，必须逐一检查以下 8 类 UI 元素。**即使尺寸很小也要报告**（识别阈值：<20px 的图标/按钮也必须识别）。

## 必检元素清单

| # | 类别 | 识别要点 | 常见位置 |
|---|------|---------|---------|
| 1 | **标题文字** | 区域标题、面板名称、图表标题 | 每个 section 的 header |
| 2 | **按钮/可点击项** | 操作按钮、tab 标签、链接、图标按钮 | header 行右侧、操作区 |
| 3 | **Badge/标签** | 状态徽章、数量角标、分类标签 | 按钮/卡片右上角 |
| 4 | **图标** | 功能图标、状态图标、装饰图标 | 标题旁、按钮内、卡片中 |
| 5 | **图表** | 折线图/柱状图/饼图/仪表盘/gauge | body 主区域 |
| 6 | **表格/列表** | 数据表格、列表项、卡片列表 | body 区域 |
| 7 | **表单控件** | 下拉框、输入框、开关(toggle)、复选框 | 筛选区/header行 |
| 8 | **装饰元素** | 分隔线、背景渐变、边框、圆角容器 | 全局 |

## 特殊识别规则

### 小尺寸元素（<20px）
- **不能因为小而忽略**：关闭按钮(×)、设置图标(⚙)、更多按钮(…) 等
- 必须报告其存在，即使无法确定具体功能

### 图表子元素
- **图例(legend)**：必须在 charts[].legend 中列出每项
- **坐标轴标签**：记录在 axes 字段
- **tooltip 格式**：如有明显格式则记录

### 细粒度文本（图表/时间轴/数据标签）
- **必须逐一识别所有小文本**，即使字号 <14px 也不能忽略。这些是还原设计的关键信息：
  - **时间轴刻度**：如「2小时前」「1小时前」「当前时间」「1小时后」「2小时后」「24小时」
  - **坐标轴刻度值**：如「4000」「3000」「2000」「1000」「0」
  - **图例文字**：如「实际流量」「预测流量」
  - **数据标签/方向标注**：如「北京方向」「上海方向」「建议分流」「16时」
  - **百分比/准确率标签**：如「准确率98%」「准确率96%」「准确率92%」
  - **统计数值**：如「d-82,379」「d-34,620」
- 这些文本若遗漏，会导致生成组件缺失坐标轴、图例、时间轴等关键信息，视觉还原严重失真

### Header 控件（header.controls）
- 这是**关键字段**，直接影响代码生成是否包含操作按钮
- 仔细检查标题行右侧是否有任何可点击元素
- 常见控件：刷新、导出、全屏、设置、更多、关闭等
