# 坐标轴结构化格式指南

## 目标

将图表的坐标轴信息从**字符串描述**升级为**结构化对象**，方便下游直接消费。

## 格式定义

```json
{
  "xAxis": {
    "unit": "",
    "label": "时间",
    "type": "category",
    "data": ["00:00", "04:00", "08:00", "12:00", "16:00", "20:00"]
  },
  "yAxis": {
    "unit": "ppm",
    "label": "浓度",
    "type": "value",
    "min": 0,
    "max": null,
    "data": null
  }
}
```

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| unit | string | 否 | 物理单位（如 ppm, ℃, %, m/s） |
| label | string | 是* | 轴标签文字（如 "时间"、"浓度"），无则留空 |
| type | string | 是 | `"category"` (离散) 或 `"value"` (连续) |
| data | array/null | category 时必填 | 离散值列表 |
| min | number/null | value 时可选 | 最小值 |
| max | number/null | value 时可选 | 最大值 |

## 常见类型判断

| 图表类型 | X 轴 | Y 轴 |
|---------|-------|-------|
| 折线图(时序) | category (时间点) | value (测量值) |
| 柱状图(对比) | category (类别名) | value (数值) |
| 饼图 | 无（饼图无坐标轴）| 无 |
| 仪表盘/gauge | 无 | value (当前值+范围) |

## 从图像提取技巧

1. **找轴标签文字** — 通常沿轴线方向排列的文字
2. **找刻度数值** — 轴上的数字标记
3. **找单位符号** — 轴末端或标签旁的小字（ppm, ℃, % 等）
4. **判断连续 vs 离散** — 时间/类别 → category；数值 → value
