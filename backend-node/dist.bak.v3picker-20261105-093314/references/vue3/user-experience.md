# 交互体验与用户体验规范

## Loading 状态管理
- [ ] 是否使用单例全局 Loading？
- [ ] 是否有延迟显示（≥300ms）？
- [ ] 是否在 nextTick 后关闭？
- [ ] 是否有超时自动关闭机制？
- [ ] 是否有淡入淡出动画？
- [ ] 文案是否明确？

### Loading 延迟显示规则
| 操作预计耗时 | 延迟显示策略 | 说明 |
|-----------|-----------|------|
| < 300ms | 不显示 | 避免闪烁 |
| 300ms-1s | 延迟300ms显示 | 若完成则不显示 |
| > 1s | 立即显示 | 告知用户需要等待 |

### Loading 级别
| 级别 | 范围 | 示例 |
|-----|------|------|
| **L1** | 应用级全局 | 路由切换、登录、支付 |
| **L2** | 组件/模块级 | 表格刷新、弹窗加载 |
| **L3** | 元素级 | 按钮微状态 |

## 按钮防重机制
- [ ] 点击后是否立即禁用按钮？
- [ ] 是否实现点击防抖（300ms-1s）？
- [ ] 按钮是否显示 loading 状态？
- [ ] 失败后是否恢复按钮可用？
- [ ] Enter 键是否防重？

### 按钮防重实现
```javascript
// ✅ 防重实现
const isSubmitting = ref(false)

const handleSubmit = async () => {
  if (isSubmitting.value) return  // 防重

  isSubmitting.value = true
  try {
    await submitForm()
  } finally {
    isSubmitting.value = false
  }
}
```

### 按钮防重级别
- **绝对关键按钮**（认证、支付、删除）：立即disabled + 300ms防抖
- **重要按钮**（创建、更新）：立即disabled + 1秒防抖
