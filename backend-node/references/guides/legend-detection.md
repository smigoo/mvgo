# 图例检测详细指南

## 图例识别的重要性

图例(legend)是图表可读性的关键。缺失图例信息会导致：
- 生成的图表无法显示系列名称
- 用户无法区分不同数据系列
- 颜色映射错误

## 图例位置 9 值体系

| 值 | 含义 | 典型布局 |
|---|------|---------|
| `top` | 图表上方居中 | 水平排列，图例在标题下方、绘图区上方 |
| `bottom` | 图表下方居中 | 水平排列，X 轴标签下方 |
| `left` | 图表左侧 | 垂直排列，Y 轴左侧 |
| `right` | 图表右侧 | 垂直排列，绘图区右侧（最常见）|
| `top-left` | 左上角 | 紧贴绘图区左上角 |
| `top-right` | 右上角 | 紧贴绘图区右上角 |
| `bottom-left` | 左下角 | X 轴左端下方 |
| `bottom-right` | 右下角 | X 轴右端下方 |
| `inside` | 图表内部 | 浮于绘图区之上（少见）|

## 2 步检测流程

### Step 1：确认图例存在
观察图表周围是否有：
- **色块 + 文字**的组合（如 ■ CO₂）
- **线条样式 + 文字**的组合（如 ―― 实线 / - - 虚线）

### Step 2：确定位置和格式
```
图例在哪？ → 确定 legendPosition（从 9 值中选择）
有几个系列？ → legend 数组长度 = 系列数量
每个什么颜色？ → seriesColors 数组对应每个系列的色值
水平还是垂直？ → legendType: "horizontal" | "vertical"
```

## 常见遗漏场景

| 场景 | 为什么容易漏 | 解决方法 |
|------|-------------|---------|
| 小尺寸图表 | 图例字体小，看起来像装饰 | 放大检查图表区域四周 |
| 单系列图表 | 认为不需要图例 | 仍需报告（单系列也有图例） |
| 图例被截断 | 只看到部分 | 报告可见部分，标注 "partial" |
| 内嵌图例 | 图例在绘图区内部 | 检查图表四角和边缘 |
