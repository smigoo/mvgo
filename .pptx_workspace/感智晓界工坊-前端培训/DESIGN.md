# DESIGN.md · 感智晓界工坊-前端培训（商务专业风）

## 1. 画布与母版（A/B/C 三区，1280×720）

| 母版区 | 位置 | 高度 | 内容规则 |
| - | - | - | - |
| A 标题块 | 0–120px | 120px | 主标题 32–38px bold，左侧 6px 主色竖条 |
| B 内容区 | 120–660px | 540px | 正文/图表/卡片，padding 左右 64px |
| C 页脚条 | 660–720px | 60px | 左：课程名 14px 灰；右：页码 `NN / 20` 14px 灰 |
| 页面 padding | 上 20 / 下 20 / 左 64 / 右 64 | — | 封面/理念/结束页可自定义 |

封面、P6 理念页、P20 结束页采用全幅自定义版式（无 C 区或弱化）。

## 2. 颜色系统（≤4 hex 主色 + 中性）

| 角色 | hex | 用途 |
| - | - | - |
| 主色 primary | `#1E3A8A` | 标题条、主色块、时间轴、流程主线 |
| 辅色 secondary | `#0EA5E9` | 卡片头、图表第二系列、图标、分隔线 |
| 强调 accent | `#F59E0B` | 焦点数字、CTA、核心标注（仅 ≤10% 面积） |
| 文本 text | `#1E293B` | 正文、标题文字 |

中性（不计入主色池）：背景 `#FFFFFF` / 浅底 `#F1F5F9` / 边框 `#E2E8F0` / 页脚灰 `#64748B`。

### 2.1 色彩面积分配
- 主色 ≤ 60%（标题条、大色块、流程主线）
- 辅色 ≤ 30%（卡片背景、图标、分隔）
- 强调 ≤ 10%（焦点数字/标注）；Hero 页（P1/P6/P20）可升至 15–20%
- 中性 剩余（文本、页脚、边框、浅底）

### 2.2 渐变与半透明
- 标题条/卡片头：`linear-gradient(135deg, #1E3A8A 0%, #0EA5E9 100%)`
- 浅色覆盖：`rgba(30,58,138,0.06)`
- 卡片浮起：`boxShadow: '0 4px 16px rgba(15,23,42,0.08)'`
- 封面/理念页背景：`linear-gradient(135deg, #0F172A 0%, #1E3A8A 100%)` + 抽象网格 SVG

## 3. 字体系统（≤2 家族）

| 层级 | 字号 | 字重 | 行高 | 字体 |
| - | - | - | - | - |
| 封面主标题 | 64 | bold | 1.2 | `"PingFang SC","Helvetica Neue",sans-serif` |
| 章节/理念大字 | 56 | bold | 1.1 | 同上 |
| 页面主标题(A区) | 34 | bold | 1.3 | 同上 |
| 卡片小标题 | 24 | 600 | 1.4 | 同上 |
| 正文 | 22 | regular | 1.55 | 同上 |
| 引文/要点 | 20 | regular | 1.5 | 同上 |
| 页码/脚注 | 14 | regular | 1.4 | 同上 |
| 巨型锚点数字 | 72–96 | bold | 1.0 | 同上（与正文同族不同字重） |

标题与正文同族，靠字重/字号拉开层级。

## 4. 信息密度（默认留白 ≤ 35%）
- 内容页正文 ≥ 180 字；卡片每卡 ≥ 100 字（合计 ≥ 300）。
- 演示预留页（P12–P16）为特例留白型（≤40%），但必须有「演示预留」徽标 + 建议素材 + 讲解要点三项实体，禁止空白。
- 容器填充率 ≥ 85%：卡片内文字钉底用 `marginTop:'auto'` / 父 `justifyContent:'space-between'`。

## 5. 配图系统（全部 SVG / FAIcon，无 ImageGen 依赖）
- L1 主视觉：封面/P6 抽象科技网格 SVG（背景网格、抽象几何概念页，允许 SVG）。
- L2 支撑图：P4 时间轴、P11 步骤流、P18 收束框 —— 均为结构化 SVG（时间轴/流程/矩阵，允许 SVG）。
- L3 角标：全篇统一页脚课程名 + 页码；演示页统一「演示预留」徽标位置（左上 A 区）。
- 禁止：用 SVG 几何冒充具象场景（本 deck 无具象场景需求）；禁止 200×70 装饰小贴片。
