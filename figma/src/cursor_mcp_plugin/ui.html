关于

          

            把 Figma 里 Frame 2136、Rectangle 8 这类默认图层名改成看得懂的名字，按模块分组，标上导出设置，整理完导出一份结构清单（结构契约 → mvgo）。只改名字、分组和导出设置，样式不改；「仅结构化整理」这类零 token 工具不需要填 Key。
          

          
使用步骤

          
    
            
  1. 在 Figma 里选中组件根节点，打开插件点「整理」；也可以用「仅结构化整理」。
    2. 
            
  2. 默认不用启动终端，插件直连网关；只有网关报跨域时，mac 双击 start-relay-mac.command、Windows 双击 start-relay-win.bat，再展开「⚙️ 高级设置」连接本地代理。
    3. 
            
  3. 整理完点「导出结构契约」，把结构清单贴给 mvgo 生成代码；导出设置随图层一起带出。
    4.
