# 组件生成页 · 输入来源体验优化方案

## 结论

当前问题不是控件样式，而是截图、Figma、文本三种来源同时出现，用户需要自行判断“填哪一个”和“系统最终采用哪一个”。推荐改为：**先选择来源，再显示对应输入；一次任务只有一个生效来源。**

## 当前体验问题

1. 外层状态框、内层上传框、Figma 输入框、文本框形成多层边框，视觉噪声较高。
2. 三种输入同时展示，缺少明确主次，用户无法快速确认当前生效来源。
3. 文本 / HTML 尚未开放却占据主流程空间，制造无效选择。
4. 历史记录按钮与输入框分离且面积偏大，容易被误认为主要操作。
5. 截图上传后仍保留大面积上传区，浪费左栏空间。
6. 截图只能使用 Lite，但界面仍展示 Max 再用提示解释，规则没有被产品行为直接表达。

## 推荐结构

### 1. 来源选择

使用二段式分段控件：

- 截图
- Figma

首次使用默认“截图”；后续记住用户最近一次选择。文本 / HTML 在功能可用前不进入主流程，也不显示禁用输入框。

### 2. 截图状态

空状态：

- 单一上传区，高度约 160–180px。
- 主文案：“选择或粘贴截图”。
- 次文案：“拖拽到这里，或按 Ctrl+V”。
- 底部说明支持格式和单张限制。

上传成功：

- 上传区收敛为约 88–104px 的预览行。
- 展示缩略图、文件名、像素尺寸和文件大小。
- 提供“替换”和删除图标操作。
- 图片解析失败时在预览行下方显示行内错误，不使用 alert。

### 3. Figma 状态

- 显示可见标签“Figma 文件或节点链接”，不能只依赖 placeholder。
- 历史记录作为输入框尾部图标或下拉入口，不单独占大按钮。
- 粘贴后自动解析并显示文件名、节点名和尺寸。
- 校验状态使用行内反馈：解析中、链接有效、链接无效、无权限。
- 明确显示当前可选择 Lite / Max。

## 配置联动

| 当前来源 | 生成规格 | 界面行为 |
|---|---|---|
| 截图 | 固定 Lite | 不展示不可用 Max；显示“Lite · 布局还原”摘要 |
| Figma | Lite / Max | 正常展示规格切换，并说明两者结果差异 |
| Vue3 | 无面板类型 | 隐藏微码专属字段 |
| 微码 | 显示面板类型 | 默认值可直接使用，详细说明弱化 |

需求文档、组件名称等低频可选项建议收进“更多设置”，默认折叠。主路径只保留来源、代码类型、生成规格和生成按钮。

## 状态模型

建议新增显式状态：

```ts
type SourceMode = 'screenshot' | 'figma'
```

规则：

1. `sourceMode` 是当前来源唯一真值，不再根据多个输入框内容猜测来源。
2. 切换来源时可以保留未激活来源的本地草稿，避免误切造成数据丢失。
3. 组装请求时只读取当前来源字段：截图只发 `imageBase64`，Figma 只发 `figmaUrl`。
4. 在任意位置粘贴图片时可自动切到截图；粘贴合法 Figma URL 时可自动切到 Figma，并给出轻量提示。
5. 生成期间锁定来源切换，终止或结束后恢复。

## 主按钮

按钮文案应随上下文变化：

- 截图 + Vue3：`使用截图生成 Vue3`
- 截图 + 微码：`使用截图生成微码组件`
- Figma + Lite：`生成 Lite 组件`
- Figma + Max：`生成 Max 组件`

按钮禁用时，在按钮下方显示一条具体原因，例如“请先上传截图”或“请输入有效的 Figma 节点链接”。不要使用泛化提示。

## 视觉规格

- 移除当前 InputStateZone 的厚外框，左栏本身已经提供区域边界。
- 输入控件圆角控制在 8px 左右，边框 1px；上传区使用单层虚线。
- 来源切换与内容区间距 12px，配置分组间距 24px。
- 历史记录、删除、替换使用图标按钮并提供 tooltip。
- 完整支持 hover、focus-visible、disabled、loading、error、success 状态。
- 键盘可通过左右方向键切换来源 Tab，交互目标不小于 40×40px。

## 实施优先级

### P0

- 增加截图 / Figma 来源切换。
- 一次只展示一种输入。
- 请求只提交当前来源字段。
- 隐藏未开放的文本 / HTML 输入。
- 修复截图来源下 Lite / Max 的联动。

### P1

- 截图上传后切换为紧凑预览行。
- Figma 链接增加解析中、成功和失败反馈。
- 历史记录改为输入框内入口。
- 主按钮改为上下文文案。

### P2

- 需求文档和组件名称放入“更多设置”。
- 记住最近来源和最近规格。
- 支持智能粘贴后自动切换来源。

## 验收标准

1. 用户进入页面后 2 秒内能判断第一步操作。
2. 任意时刻只有一个可见、可提交的来源输入。
3. 截图任务请求不含 `figmaUrl`；Figma 任务请求不含 `imageBase64`。
4. 截图模式不出现可点击或禁用的 Max 选项。
5. 未开放功能不占用主流程空间。
6. 所有错误均在对应控件附近显示，且说明如何修复。
