# 组件生成页 · 状态设计规格（空状态 + 生成中）

> 基于前期 UX 分析结论的落地设计。当前 Ardot 画布适配器不可用，本文档作为可直接交付开发的状态规格（布局 / 组件 / Token / 线框图）。
> 后续画布恢复后，可据此 1:1 还原为可视化原型。

---

## 一、设计原则（回顾）

| 原则 | 说明 |
|---|---|
| **右侧不空** | 非生成态下右侧用「引导 + 历史 + 推荐」三层内容兜底，杜绝空间浪费 |
| **状态驱动** | 右侧面板内容随任务状态切换：空 → 配置摘要 → 生成中（进度）→ 完成（结果）|
| **反馈可见** | 生成中必须有进度条、阶段指示、实时日志，让用户确认「系统在干活」|
| **标签身份鲜明** | V3/MC 方块 + Lite/Max 胶囊，沿用已定稿视觉语言 |

### 2.2 左侧表单（380px 固定）

| 模块 | 组件 | 状态 |
|---|---|---|
| 面板头 | 图标 + 「新建生成任务」+ 面包屑 | 静态 |
| 模式切换 | Segmented：[单个组件]（选中白底）/ [批量生成]（灰）| 单选 |
| 输入来源 | 三 Tab：[截图]（蓝选中）/ [Figma] / [HTML] | 单选 |
| 输入区 | 虚线拖拽框 + 图标 + 「粘贴截图、拖拽图片或输入 Figma 链接」+「支持 Ctrl+V 粘贴」| 可交互 |
| 组件配置 | 行1：[Vue3 绿方块] / [微码 灰]; 行2：[●Lite 绿胶囊] / [Max 灰胶囊] | 多选语义（类型单/等级单）|
| 组件命名 | 文本输入占位 `c-start-card` | 可输入 |
| 提交 | 主按钮「⚡ 开始生成」（蓝，带阴影）+ 次要链接「或上传截图开始」| 可点击（无输入时禁用）|

### 2.3 右侧面板（解决"太空"的三层兜底）

右侧在**未生成且未填完**时，按优先级填充，保证不空：

1. **第一层：配置摘要卡**（输入后实时显示已选 V3/MC + 来源 + Lite/Max 标签）
2. **第二层：快速上手引导**（4 步：粘贴 → 选类型 → 点生成 → 预览）+ 最近任务列表
3. **第三层：推荐模板**（卡片类/表单类/列表类/弹窗类，填充空间 + 提供探索入口）

> 空状态插画占位：居中图标 + 文案「输入截图或 Figma 链接后实时预览生成结果」。

### 3.2 左侧表单（禁用态）

- 所有输入控件置灰（`#F3F4F6` 底 + `#9CA3AF` 文字），`disabled` 态
- 「开始生成」按钮变为「⏳ 生成中…」，灰蓝禁用样式，不可重复点击
- 顶部状态徽章从绿色「等待输入」切换为蓝色「生成中 · 预计 1-2 分钟」

### 3.3 右侧面板（进度驱动）

| 模块 | 内容 |
|---|---|
| 进度头 | 组件名 + 类型标签 + 进度百分比「62%」+ 取消按钮「✕ 取消生成」|
| 进度条 | 实色填充 + 百分比文字 |
| 阶段指示器 | 4 阶段：①分析 ✓ ②生成中 ● ③校验 ○ ④导出 ○（已完成打勾、进行中高亮、未开始灰）|
| 实时日志 | 滚动日志区：解析 → 匹配模板 → 生成 SFC → 注入声明，逐行追加 |
| 输入预览 | 左侧显示已载入的截图/链接缩略图 |
| 实时缩略图 | 右侧显示组件渲染预览占位（SSE 推送首帧后替换）|

> 取消按钮调用任务终止链路（`tasksService.cancelTask` → `controller.abort()`），与后端 abort 注册一致（见 workspace 记忆「任务终止链路」）。

## 五、实现建议（前端对照）

1. **状态机**：`idle → configuring → generating → done/error`，右侧面板按 `status` 渲染不同子组件。
2. **右侧不空策略**：`idle` 时渲染 `QuickStart + RecentTasks + Templates`；`configuring` 时叠加 `ConfigSummary`；`generating` 时渲染 `ProgressPanel`；`done` 时渲染 `ResultPanel`。
3. **进度对接**：`generating` 状态订阅 SSE（`/progress/:sessionId`），更新进度条 + 阶段 + 日志；取消走 `cancelTask`。
4. **标签组件复用**：直接复用已定稿的 V3/MC 方块 + Lite/Max 胶囊组件，保证三处（表单/摘要/任务卡）视觉一致。
