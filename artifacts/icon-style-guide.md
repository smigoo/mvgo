# 网站深浅主题 icon 风格规范

## 设计定位
这套网站更像后台工具型产品，不适合做高饱和、发光、渐变、厚拟物 icon。
目标风格应是：
- 线性描边为主
- 容器轻，语义强
- 浅色清爽，深色克制
- 页面标题图标和操作图标属于同一语言，但层级明确区分

## 总原则
1. 统一使用线性 icon，不混用填充风和线性风。
2. 默认使用中性灰或品牌蓝，不让每个 icon 都变成功能色。
3. 功能色只给状态 icon 用：成功、警告、失败。
4. 深色主题不做 glow、不做 neon、不加外发光。
5. 空状态 icon 必须弱化，不能比正文更抢眼。

## 四层 icon 体系

### 1. 页面标题 icon
用于页面主标题左侧，如组件生成、任务中心、页面生成、接口生成。

- 容器尺寸：`42px ~ 44px`
- 圆角：`12px`
- 形式：浅底容器 + 线性 icon
- 图标尺寸：`18px ~ 20px`
- 语义：页面级，不参与状态表达

浅色主题：
- 容器：`var(--brand-bg)`
- 描边 / 图标：`var(--brand)`
- 边框：可选 `var(--brand-border)`

深色主题：
- 容器：`var(--brand-bg)` 或 `rgba(59,130,246,0.12~0.16)`
- 描边 / 图标：`var(--brand-light)` 或 `var(--brand)`
- 不要发光阴影

### 2. 操作按钮 icon
用于刷新、下载、预览、返回、关闭、删除、设置等。

- 图标尺寸：`16px ~ 18px`
- 按钮容器：`28px ~ 36px`
- 形式：中性按钮优先，hover 再强调
- 默认颜色：`var(--text-secondary)`

浅色主题：
- 默认：`var(--bg-hover)` / `var(--border-default)` / `var(--text-secondary)`
- hover：`var(--brand-bg)` / `var(--brand)`

深色主题：
- 默认：`var(--bg-alt)` / `var(--border-default)` / `#cbd5e1` 级别文本
- hover：切到品牌蓝容器，但只提亮一档

规则：
- 删除按钮可以走 error 语义
- 普通操作按钮不要默认上色
- 一个工具条里只允许一个主强调按钮

### 3. 状态 icon
用于成功、运行中、警告、失败、取消等。

- 图标尺寸：`14px ~ 18px`
- 可配圆形或胶囊容器
- 状态色只在这里使用

状态建议：
- 成功：绿色
- 警告：橙色
- 失败：红色
- 运行中：品牌蓝
- 已取消：中性灰

浅色主题：
- 容器：对应语义色的 50 / 100 层
- 线条：对应语义色 600 层

深色主题：
- 容器：对应语义色 `rgba(..., 0.12 ~ 0.16)`
- 线条：对应语义色提亮一档
- 避免高饱和大面积铺满

### 4. 空状态 / 占位 icon
用于“暂无任务”“暂无记录”“没有结果”等场景。

- 图标尺寸：`20px ~ 24px`
- 容器可有可无
- 必须弱化处理

浅色主题：
- 颜色：`var(--text-quaternary)` 或 `var(--c-gray-400)`
- 容器：`var(--bg-hover)` 或无容器

深色主题：
- 颜色：`#94a3b8` 一类中性灰
- 容器：`var(--bg-alt)`

规则：
- 空状态不用品牌蓝主色
- 不用功能红/绿/橙

## 推荐造型规范

### 线条
- 线宽：`1.75px ~ 1.9px`
- 线帽：`round`
- 线拐角：`round`

### 容器
- 标题 icon：圆角方块
- 状态 icon：圆形优先
- 操作按钮：小圆角矩形

### 阴影
- icon 容器默认不加阴影
- 只在卡片 hover 或按钮 hover 时，跟随整个组件轻微抬升
- 不给 icon 单独做投影

## 和现有 token 的映射
你这套站现在已经有足够 token，不需要新增复杂色板。

直接复用：
- 品牌：`--brand` `--brand-bg` `--brand-border` `--brand-light`
- 中性：`--text-primary` `--text-secondary` `--text-tertiary` `--border-default` `--bg-hover` `--bg-alt`
- 状态：`--success` `--success-bg` `--warning` `--warning-bg` `--error` `--error-bg`

## 页面落地建议

### 第一批统一对象
1. 页面标题区
   - 组件生成
   - 页面生成
   - 任务中心
   - API 接口生成

2. 操作按钮区
   - 刷新 / 下载 / 预览 / 关闭 / 返回 / 设置

3. 任务与历史状态
   - 成功 / 运行中 / 失败 / 已取消

4. 空状态
   - 暂无任务
   - 暂无生成记录
   - 暂无结果

### 第二批再统一
1. 快捷卡片左侧小图标
2. 统计卡片中的辅助图标
3. 上传、文档、绑定类功能 icon

## 明确不建议
- 不建议用渐变 icon
- 不建议深色主题下做霓虹蓝发光
- 不建议一页里混用 Ant 线性图标和自定义填充 icon
- 不建议在普通操作按钮上长期使用 success / error / warning 色

## 结论
最适合你这个站的，是一套“品牌蓝标题 icon + 中性操作 icon + 语义状态 icon + 弱化空状态 icon”的四层体系。

如果要继续推进，最值得做的是：
- 先统一所有页面标题区 icon
- 再统一任务中心、组件生成页、接口页的操作按钮 icon
- 最后收口状态类和空状态类 icon
