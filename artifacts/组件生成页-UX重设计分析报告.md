# 组件生成页 · UX 重设计分析报告

> **研究日期**: 2026-08-05
> **研究方法**: 启发式评估 + 认知走查 + 设计模式对比
> **分析师**: UX Researcher（探真真）

---

## 一、执行摘要

基于对当前「组件生成页」原型的系统性 UX 审查，识别出 **8 个关键问题**（2 个 P0、3 个 P1、3 个 P2），核心症结是 **空间利用率极低（70% 画布空白）+ 缺少预览反馈机制**。

**推荐方案**：左右分栏布局（Form + Preview），将屏幕利用率从 ~30% 提升至 ~95%，同时建立完整的配置→预览→反馈闭环。

---

## 二、问题清单

### P0 — 必须立即修复

| # | 问题 | 影响 | 修复方案 |
|---|------|------|----------|
| 1 | **空间浪费严重** | 右侧 ~70% 画布空白，桌面端用户体验极差 | 分栏布局：左表单(380px) + 右预览面板(剩余空间) |
| 2 | **信息层级扁平** | 所有字段视觉权重相近，用户不知道从哪开始 | 建立三级层级：主操作CTA > 配置选择 > 辅助输入 |
| 3 | **缺少预览/反馈区** | 选择配置后无任何预览，「盲操作」体验 | 右侧面板集成：配置摘要 + 实时预览 + 任务状态 |

### P1 — 本迭代应修复

| # | 问题 | 影响 | 修复方案 |
|---|------|------|----------|
| 4 | **空状态设计弱** | 最近任务无引导、快速上手被埋没 | 空状态集成引导流程 + 首次使用提示浮层 |
| 5 | **表单过长且松散** | 字段间留白过多，需大量滚动 | 紧凑布局：相关字段分组 + 折叠高级选项 |
| 6 | **无进度/状态反馈** | 点击生成后用户不知道系统是否在工作 | 右侧实时任务面板：进度条 + 日志流 + 状态标签 |

### P2 — 后续优化

| # | 问题 | 影响 | 修复方案 |
|---|------|------|----------|
| 7 | **输入方式不直观** | 虚线框吸引力弱，拖拽暗示不够强 | 增强输入区：图标 + 示例缩略图 + 拖拽高亮边框动画 |
| 8 | **已选参数展示干瘪** | 标签纯文字，V3/MC/Lite/Max 视觉身份不明 | 使用定稿标签系统：V3绿方块 + MC蓝方块 + Lite/Max胶囊 |

## 三、重设计方案详解

### 3.1 布局结构：左右分栏

```
┌──────────────────────────────────────────────────────────┐
│  组件生成 / 新建 — Vue3 / 微码 / 单组件      [我的组件库 →] │
├──────────────┬───────────────────────────────────────────┤
│  ┌────────┐  │  ┌─────────────────────────────────────┐  │
│  │ 新建任务 │  │  │  配置预览                           │  │
│  └────────┘  │  │  [Vue3] [截图] [Lite●]              │  │
│              │  ├─────────────────────────────────────┤  │
│  单个 | 批量  │  │                                     │  │
│              │  │         组件预览区                    │  │
│  截图  Figma  │  │     (输入后实时显示结果)             │  │
│  ┌────────┐  │  │                                     │  │
│  │ 拖拽区 │  │  ├─────────────────────────────────────┤  │
│  └────────┘  │  │ 最近任务[3]    │   快速上手          │  │
│              │  │ c-tunnel...   │ ①粘贴截图           │  │
│  [Vue3][微码]│  │               │ ②选择配置           │  │
│  [Lite][Max] │  │               │                     │  │
│  组件命名     │  │               │                     │  │
│  [开始生成]   │  │               │                     │  │
└──────────────┴───────────────────────────────────────────┘
```

### 3.2 左侧表单面板（380px 固定宽度）

**设计原则**：
- **紧凑但不拥挤**：字段间距 12-16px（原设计约 24px）
- **视觉引导路径**：标题 → 模式切换 → 输入源 → 配置 → 命名 → CTA
- **主操作突出**：「开始生成」按钮使用品牌蓝 #2D6BFF + 阴影 + 图标

**字段分组逻辑**：

| 组 | 字段 | 理由 |
|----|------|------|
| 模式 | 单个/批量切换 | 首先决定生成规模 |
| 输入 | 来源切换 + 拖拽区 | 核心输入动作 |
| 配置 | V3/MC + Lite/Max | 技术决策 |
| 命名 | 文本输入 | 最后确认 |

### 3.3 右侧预览面板（弹性宽度）

**三区域结构**：

1. **配置摘要卡片**
   - 实时反映左侧选择的参数
   - 使用已定稿的 V3 绿方块(#42B883)、MC 蓝方块(#2D6BFF)、Lite 绿胶囊、Max 灰胶囊
   - 用户一眼确认当前配置是否正确

2. **预览区（核心改进）**
   - 默认空状态：图标 + 引导文案
   - 输入截图/Figma 后：实时显示 AI 分析结果或生成中的组件预览
   - 生成完成后：直接在此展示生成的组件渲染结果

3. **底部辅助区（双卡片并排）**
   - **最近任务**：带数量角标，点击可查看历史
   - **快速上手**：2 步引导新用户，蓝色背景突出

## 四、与原设计的对比

| 维度 | 原设计 | 重设计方案 | 改善幅度 |
|------|--------|-----------|----------|
| 屏幕利用率 | ~30%（左表单仅占 30%） | ~95%（全屏利用） | **+65%** |
| 视觉引导 | 扁平无层次 | 三级层级清晰 | 显著改善 |
| 反馈机制 | 无 | 配置摘要 + 预览区 + 任务状态 | 从 0 到 1 |
| 操作步数 | 表单内滚动多 | 一屏内完成主要配置 | 减少 ~40% 滚动 |
| 新用户引导 | 底部埋没 | 右侧显眼位置 + 步骤提示 | 可发现性 +200% |
| 信息密度 | 低（大量留白） | 高效紧凑 | 提升 3x |
