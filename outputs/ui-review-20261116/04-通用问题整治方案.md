## 一 · 唯一事实源选定（先定契约，再改代码）

| 概念 | 唯一事实源 | 派生关系 | 现状违规 |
|---|---|---|---|
| **段高比例** | `topHeights[]`（Figma 实测区块高）**经 Σ 归一** | `r_i = h_i / (Σh + Σgap)`，Σr 恒 = 1 | 另有 px 形态 `heightPx` 直接落盘（E1/E2） |
| **根高（仅作比例分母 + 审计）** | `_figma-size.json#document.absoluteBoundingBox` | 只用于校验 `Σ(h_i)` 与根高的自洽性；**不得**作落盘尺寸 | 被 `healRootFixedSize` 丢弃，段高环节零消费（E3） |
| **根容器尺寸** | **宿主契约**（default-panel 的 `.pannel-content` ⇒ `width:100%` + 撑满高） | 与 Figma 设计框尺寸**无关** | 4/6 硬编码绝对 px（E4），自愈漏网（E5） |
| **vision 骨架** | `(fileKey, nodeId, **语义内容指纹**)` | 指纹 = 对 Figma 节点树做**规范化投影**（只取影响布局/文案的字段：`id/type/name/characters/bbox/layoutMode/children` 递归；**剔 `lastModified` / 缩略图 URL / 时间戳**） | 现键 `vision_<fileKey>_<nodeId>_<target>` **无内容指纹**（`visual-parser.js:4583-4592`） |

**不硬编码的自证方式**：
- 段高：`Σr = 1` 是**数学不变量**，不是阈值；改 Σ=1 不需要任何常量。
- 根容器：用**已有语义标记**（`data-mvgo-geom="root"` / `data-absorbed-host="root"`）识别，**不是类名白名单**（E6 已具备，零新增约定）。
- vision 指纹：规范化投影是**字段白名单 + 递归稳定序**，非哈希魔数；须过三对照（见 §五）。

## 三 · 每项六问评审（仅对「动码」项；只读项免）

### B1 · 段高量纲收敛为单一（Σ=1 比例）

| 问 | 答 |
|---|---|
| ① 根治 or 补丁 | **根治**。物理量是「段占容器高的比例」，唯一正确表示是 Σ=1 的 flex-grow；现状 px basis 与容器高**无函数关系**，任何「算个缩放系数去乘」都是补丁 |
| ② 判据落哪层 | **装配出口（`buildDeterministicIndexTemplate`）**：写出前断言 `Σr ≈ 1`。不在产物后处理、不在门禁 |
| ③ 补丁防什么 / 根治项是什么 | 补丁 = 在产物里改某个 sech 的 px 值；根治项 = **px carrier 整体退役**，`carrier` 概念只留「inline 比例」一种，`layoutStyle` 不再产 px |
| ④ 上游（入参/结构是否变、新输出是否纯附加） | 入参不变：仍用 `topHeights[]`；`_figma-size.json` **新增**为比例分母/审计输入（纯附加读取，不改其写入）。`layoutStyle` 由「px 规则」变「比例规则」= **输出语义变更**（非纯附加），须同轮改四象象限与 spec |
| ⑤ 下游（消费者/剥除范围严格限定） | 消费者清单：`resource-mounter.js` 规则②(3036-3092)/规则⑥(3360-3363) 的 `classifyGrowScale` 量纲判定；`FLEX-004/FLEX-005`（`code-structure-validator.js` + `flex-sibling-guard.js`）；`section-stack-contract.js:243`（亦写 `flex: 0 1 <px>px` — **须同源收口**）；`px2rem`。**剥除范围严格限定**：只动「本函数产出的 sech 段高声明」，不碰 gap/margin 规则 |
| ⑥ 其他类型逐条枚举不命中 | （a）图表段 `min-height:<px>` 是**内容最小高**，非段高分配 ⇒ 不动；（b）固定尺寸元素（icon/badge，`isFixedSizeElement`）⇒ 不参与比例，不动；（c）row 方向容器的 grow（`resource-mounter.js:3305` 已收窄）⇒ 不动；（d）`flex: 0 0 Npx` 附属区 ⇒ 不动。**真错仍 FAIL**：Σr 与 1 偏差超 ε、或段高落回 px，一律 FAIL 不放过 |

### B2 · 根容器尺寸单一来源

| 问 | 答 |
|---|---|
| ① 根治 or 补丁 | **根治**：根容器尺寸的**唯一来源是宿主契约**（撑满面板），与设计框尺寸无关 |
| ② 判据落哪层 | **根容器模板生成处 + `healRootFixedSize` 判据**（消费已有语义标记） |
| ③ 补丁防什么 / 根治项是什么 | 补丁 = 再补一条类名正则；根治项 = `healRootFixedSize` **判据从「类名尾段 `-root`」改为「消费 `data-mvgo-geom="root"` / `data-absorbed-host="root"` 标记」**，且根容器生成即写 `width:100%`／撑满（不等 LLM 犯错再自愈） |
| ④ 上游 | 入参不变；根容器模板新增语义标记消费（**标记已存在，6/6 都有**，零新增约定） |
| ⑤ 下游 | `healRootFixedSize` 的既有类名分支**保留为 legacy 兜底**（不删，避免伤存量）；剥除范围 = 仅根容器那一条规则块内 width/height 固定长度，保留 max/min/padding/gap/flex |
| ⑥ 其他类型不命中 | （a）`max-width/max-height/min-width/min-height` 不动（现有守则已保证）；（b）**子元素**固定 px 尺寸不是根容器 ⇒ 不命中（判据按标记/结构位置，不按「有 px 就改」）；（c）`-root` 存量产物仍走 legacy 分支。真错仍 FAIL：根容器仍落绝对 px ⇒ FAIL |
