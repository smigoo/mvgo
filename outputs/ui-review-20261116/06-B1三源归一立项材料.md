## 一、目标与不变量

**目标**：段高只有一种量纲——同层归一比例（`Σr ≡ 1`），px basis 退役；三处事实源收口为一条链。

**数学不变量（判据唯一来源）**：

```
r_i = h_i / (Σh + Σgap)        （h_i = Figma 实测区块高，gap_i = Figma 实测兄弟间距）
Σ r_i ≡ 1                       （含 gap 折算，与 flexItemStyleFromHeights 现行公式一致）
```

- 不是阈值、不是常量；任何实现读同一份 `topHeights[]/topGaps[]` 都必须得出同一组 r。
- `Σr` 与 1 偏差 > ε（ε=0.001，浮点累加容差）⇒ **FAIL（fail-loud）**，附段 id 明细。
- 段高声明出现 `flex: 0 1 <px>px !important` 形态 ⇒ **FAIL**（px carrier 退役断言）。
- `avg=1` 量纲（Σ=n）出现 ⇒ **FAIL**（sectionHeights 量纲迁移断言）。

## 三、spec 草案（先立后改）

### A. 不变量断言（新 spec：`section-height-normalization.spec.ts`）

```text
A1 给定 topHeights=[76,161,212,265], topGaps=[0,33,20,20]（68783bf6 真值）
   ⇒ r = [0.131,0.277,0.365,0.457]（归一到 Σh+Σgap=787）
   ⇒ 每个产物声明点的 flex-grow 与 r 的偏差 ≤ 0.001
   ⇒ 产物中不存在 `flex: 0 1 76px` 形态

A2 阳性对照：把 topHeights[1] 翻倍 ⇒ r[1] 翻倍级增长、其余收缩、Σ 仍=1

A3 鲁棒性对照：改根高（_figma-size 274→999）⇒ r 不变（比例与根高无关）

A4 阴性对照：只改颜色/文本 ⇒ 段高声明逐字不变
```

### B. 迁移断言（`sectionHeights` 量纲）

```text
B1 figma-height-ratio 产物 styles.flexGrow 的 Σ ≈ 段数 → 改后 Σ ≈ 1（±0.001）
B2 单段组件（plan 1 leaf）：r = 1（历史实锤 c46c2631 形态不回归）
B3 resource-mounter 规则② 命中映射时写 flex: <r> 1 0（值域 ≤1，classifyGrowScale 判 'ratio'）
B4 规则⑥ LLM 模板路径：内联 flex 被改写为 r 量纲（写法语义不变）
```

### C. 退役断言（px carrier）

```text
C1 buildDeterministicIndexTemplate 产物 index.vue 的 <style> 不再含 `flex: 0 1 \d+px !important`

   ⇒ 渲染高度比例与 Figma 真值比例偏差 ≤ 2%（mc-preview.png 像素剖面法）
```

## 四、六问评审（预答，实现前须再过一轮）

| 问 | 答 |
|---|---|
| ① 根治/补丁 | **根治**。px basis 与容器高无函数关系是物理错误；补丁（缩放系数、经验值）被方案明确禁止 |
| ② 判据落层 | 装配出口（S1 写出前）+ 求解出口（S2/S3 产出时）双断言 `Σr≡1`；不在门禁层、不在产物后处理 |
| ③ 补丁防什么/根治项 | 补丁 = 改某个 px 值；根治项 = 三源收口一条链 + px carrier 退役 + fail-loud |
| ④ 上游 | 入参不变（`topHeights[]/topGaps[]` 均为 Figma 实测）；`figma-height-ratio` 的 flexGrow 语义变更 = **输出语义变更**（非纯附加），prompt/文档同步 |
| ⑤ 下游 | 消费者：规则②/⑥（写法不变值换量纲）、`classifyGrowScale`（值域更安全）、`section-stack-contract`（同源收口）、`px2rem`（比例值无 px 不再转换，天然兼容）。剥除范围：仅段高声明；gap/margin 规则、`flex: 0 0 Npx` 附属区、图表 `min-height` 全部不碰 |
| ⑥ 其他类型不命中 | （a）宽度方向 `flexItemStyleFromWidths` 同构问题**不在本刀范围**（另行立项，避免一刀过大）；（b）row 容器 grow 不碰；（c）固定尺寸元素不参与比例（既有判据）；（d）单文件组件路径（`extractRootDirectChildClasses`）走同一 r，无独立实现。真错仍 FAIL：Σr 偏差、px 残留、avg=1 残留三类全 FAIL |
