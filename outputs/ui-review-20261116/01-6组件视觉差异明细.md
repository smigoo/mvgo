**根因（已定位到行）**：
1. `StatsSection.vue` 模板中数值 **确实存在**（`<span class="c-c1ac19-stat-value">6/7</span>`…）。
2. 但 `resources/styles/common.less:65-71` 给 `.c-c1ac19-stat-value` 设了
   ```less
   .c-c1ac19-stat-value {
     line-height: 1.1;
     font-variant-numeric: tabular-nums;
     -webkit-background-clip: text;
     background-clip: text;
     -webkit-text-fill-color: transparent;   /* ← 文字透明 */
   }
   ```
   **而全仓（`resources/styles/**` + `package/**`）没有任何一条为 `.c-c1ac19-stat-value` 提供 `background-image`/`background:`** —— 机器核验输出：`有背景=False`（对照组 `.c-c1ac19-section-title` `有背景=True`）。
3. `bg-stat-4.png`(159×102) / `bg-stat-5.png`(159×82) 经 OCR 返回 **空 `[]`** → 是**装饰背景/光晕图**，不是数字字形，**无法承担「让数值显形」的职责**。
   ⇒ **数值被设为透明填充且无背景 → 在浏览器中真实不可见**。这是**单点确定性缺陷，不是采样抖动**。

## 3. 需澄清的取证边界（避免误判）

- **A. 产物截图系统性含预览壳层 UI**：`frontend/src/views/preview/index.vue:19,38,80` 对**非 vue3 组件**渲染「主题切换器 + 演示主题面板说明条」（`v-if="!isVue3"` / `v-if="!isVue3 && !isEmbedded"`）。6 个组件均为 **mc-max（微码）** ⇒ `isVue3=false` ⇒ **壳层必然渲染**，截图顶部被占约 180–200px。
  截图 URL（`screenshot-renderer.js:766-770`）只带 `sessionId/type/groupId/theme`，**不带 `embedded`** ⇒ 无法关闭壳层。
  ⇒ **前序把「主题条」记为产物缺陷 D-b，实测应归因为预览壳层**；且本次「产物多」的 token 中约 6–8 条属于壳层文本，**不得计入产物缺陷**。
- **B. OCR 错字**：`坏境温度`(环境)、`父级改笛`(父级设备)、`汉示`(演示)、`烟逍/烟道机器人`、`郊翠节占岭`、`江甘碰网节点`、`降麁齤麩司具臯禁道合宝` 等，**多为 OCR 对渐变/半透明/描边文字的误读**，须以产物源码为准；**不据此改判据**。
- **C. 内容密度剖面**：`c1ac194a` 背景色检出为 `(56,255,242)`（青），四角中位数法失效 ⇒ 该组件剖面数值**不可用**，以「段高溢出 518>348」为准。
