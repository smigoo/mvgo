## 3. 归因链（每一环钉到代码/数据）

1. **vision 原始输出 = 5 段平铺**（`debug-ai-response.txt`，`layout.sections` 顶层）：`1:449 面板标题栏 / 1:412 Tab切换栏 / 1:377 / 1:388 / 1:400`。容器 `1:376 warning-list` **不是** section（是 A4 之后段树重建时归组的壳，故落盘态 1:376 `flexGrow=None`、0.123 在其 children 上）。原始输出 `grep -c '256' = 0` ⇒ 256 非模型自报，是**管线写回**。
2. **chrome 剥离先于 A4**（`visual-parser.js:1533-1542` `resolveHeaderOwner`+`stripChromeSectionsInPlace`，A4 在 `:1613`）⇒ `1:449` 被摘出 sections，**且不进 A4 的 claimedIds**。
3. **A4 ①-β idDirect 全命中 4 段**（`figma-height-ratio.js:662-688`），进 `writeSectionRatios`（`:1154`），`claimedIds={1:412,1:377,1:388,1:400}`。
4. **P0-8 `geometricUnionHeightFor`（`:1051-1140`，2026-11-14 并行会话刀）双重越权吸收**：
   - 候选过滤 `:1073` 只排除「候选**自身**被认领」，**不排除「候选是已认领锚点的祖先」**⇒ 容器 `1:376`（h170，内容块，gap=210−200=10≤32）按「内容块归上方段」并入 tab；
   - chrome 剥离掉的 `1:449`（h39.68≤40，薄条，gap=173−163.68=9.32≤32）按「薄条归下方段」也并入 tab；
   - union=256>27 ⇒ 「只升不降」（`:1194-1197`）采纳 ⇒ `256/406=0.631`、`geometryPx={h:256}`。
5. **下游忠实传导**：`figma-section-heights.js` → `resource-mounter.js` 规则⑥ → 装配层 430 分母 → inline `flex:0.595/0.116` → 视觉后果 = §1.2（tab 空撑 59.5%、卡被裁）。

**反事实**（同函数算）：只修 1:376 排除 ⇒ 76；只修 1:449 排除 ⇒ 207；全对 ⇒ 27。**两条都要堵**。
