## 二、前置实证：渲染器确定性

方法：对**同一产物** `mc-max-1794794243997-4d00060d`，用**与 `screenshot-renderer.js:1192-1198` 逐字一致的 Chromium 参数**，做 2 次独立加载 × 2 种等待时长（300ms / 3000ms）。

```
viewport : 426x807 dpr2 -> 852x1614
load1    : readyMs=2358 status=ready
load2    : readyMs=2656 status=ready
load1-300ms    11e123f2b0336849  235922B
load1-3000ms   11e123f2b0336849  235922B
load2-300ms    11e123f2b0336849  235922B
load2-3000ms   11e123f2b0336849  235922B
A==B(300 vs 3000 同页) : YES 相同
C==D                  : YES 相同
A==C(同等待 跨加载)    : YES 相同
B==D                  : YES 相同
```

⇒ **渲染器确定**（给定等待时长）。

### 唯一不确定点：300ms 动画中间态

换产物 `578712ee` 重跑同一实验：

```
load1-300ms    af2318afee03e827
load1-3000ms   5bc8aba27d97d946
load2-300ms    af2318afee03e827
load2-3000ms   5bc8aba27d97d946
A==B : NO 不同   C==D : NO 不同
A==C : YES 相同   B==D : YES 相同
```

A/B 差异空间分布：**总差异 0.06%**，集中在 band14（y=1412–1513，0.7%）与 x=532–852（右下区域）。

⇒ 结论：
- `screenshot-renderer.js:1073` 的 `setTimeout(300)` **确实早于 echarts 动画收敛**（产物未禁用动画、渲染模板也未注入禁用）；
- 但影响**仅 0.06% 局部像素** ⇒ **不足以解释** 12 样本 26%–42% 的差异；
- 因为是「固定进度的中间态」，跨样本仍**同基准可比**；只在**与设计稿对比**时会系统性偏（柱高不满 / 环形未闭合）。

## 六、本轮新增缺陷（确定性复现）

### D-a `578712ee` 渲染出现字面量 `undefined` ×4

- 录制截图 OCR：`undefined` @ (x=223,y=834,c=1.00)、(x=593,y=834,c=0.50)、(x=223,y=1100)、(x=594,y=1105)
- **重渲后 4 处坐标完全复现**（`y=834/1100, x=223/593`）⇒ **确定性缺陷，非 OCR 误读**
- 该样本正是**走自愈重试通道**的那一个（vision 覆盖校验重试轮），重试后仍产出可见坏文本
- 根因未定（`578712ee` 包内未发现字面量 `undefined` 源；`{{ }}` 渲染 undefined 通常为 `''`，故疑为字符串拼接/查表表达式）⇒ **登记为下一根治项，不在本轮动刀**

### D-b 预览页「演示主题条」污染取证区

- 占 **y=0–302（18.7% 图像高度）**，来自组件 `declare.json#themeConfig`（浅色主题/深色主题·内置），**设计稿不存在**
- 其内部排版**存在时序抖动**：同一产物录制图 vs 新渲染图在 y<302 内差 67.8%/52.5%/34.9%，而 **y>302 逐像素 0.0%**；OCR 证实是文本整体位移 22px（字体/文本测量时序）
- ⇒ 结论：**产物主体渲染逐像素可复现**，抖动只在 harness 覆盖层
