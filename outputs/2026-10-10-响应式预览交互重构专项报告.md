## 一、重构背景与目标

### 1.1 问题域

TaskDetail 预览页在 2026-10-10 前存在以下交互问题：

1. **拖拽松开后尺寸依旧变化**：拖拽路径经过 iframe 时，`mouseup` 被 iframe 内部文档吞掉，宿主 document 收不到事件 → 监听器残留、`isResizing` 卡在 true
2. **保真模式死代码链**：保真模式切换逻辑复杂，切回保真时未下发 fidelity 消息导致 iframe 内响应式状态残留（stage 溢出/input 超宽/底部漂移）
3. **缩放交互不统一**：TaskDetail 与 playground（demo）的缩放交互方式不一致，用户体验割裂
4. **默认视口尺寸不合理**：默认 1280×720 导致横向溢出，手柄落可视区外
5. **档位预设按钮冗余**：预设按钮组功能与缩放下拉重复，拖拽气泡显示信息不够直观

### 1.2 重构目标

- **根治 iframe 吞事件问题**：通过 Pointer Capture 技术确保拖拽事件不丢失
- **统一交互范式**：TaskDetail 与 playground 的缩放/拉伸交互完全对齐
- **简化代码结构**：删除保真模式死代码，降低维护成本
- **优化默认体验**：调整默认视口尺寸，确保手柄在可视区内
- **增强信息反馈**：拖拽气泡显示实际尺寸 + 相对设计稿比例

## 二、核心改动分析

### 2.1 Pointer Capture 根治 iframe 吞事件（4d5358d）

**文件**：`src/composables/useResizableFrame.ts`  
**变更**：+41/-15 行

#### 2.1.1 根因分析

拖拽手柄时，鼠标移动路径可能经过预览 iframe。由于 iframe 是独立的文档上下文，`mousemove` 和 `mouseup` 事件会派发给 iframe 内部文档，宿主 document 的监听器收不到 `mouseup` → `isResizing` 卡在 true → 松开鼠标后继续移动，尺寸依旧变化。

#### 2.1.2 解决方案

使用 **Pointer Capture API**：手柄元素调用 `setPointerCapture(pointerId)` 后，该指针的所有事件（`pointermove`/`pointerup`/`pointercancel`）恒派发给手柄元素，iframe 无法吞掉。

```typescript
// 新增 captureEl 变量记录捕获指针的元素
let captureEl: HTMLElement | null = null

function startResize(event: PointerEvent) {
  // ...
  
  // 优先 Pointer Capture
  const el = event.currentTarget as HTMLElement | null
  const pointerId = (event as PointerEvent).pointerId
  if (el && typeof el.setPointerCapture === 'function' && typeof pointerId === 'number') {
    try {
      el.setPointerCapture(pointerId)
      captureEl = el
      el.addEventListener('pointermove', onDragMove)
      el.addEventListener('pointerup', finishResize)
      el.addEventListener('pointercancel', finishResize)
      return
    } catch {
      captureEl = null
    }
  }
  
  // 兜底：不支持 Pointer Capture 的环境退回 document 监听
  document.addEventListener('mousemove', onDragMove)
  document.addEventListener('mouseup', finishResize)
}

function finishResize() {
  // ...
  if (captureEl) {
    captureEl.removeEventListener('pointermove', onDragMove)
    captureEl.removeEventListener('pointerup', finishResize)
    captureEl.removeEventListener('pointercancel', finishResize)
    captureEl = null
  }
  document.removeEventListener('mousemove', onDragMove)
  document.removeEventListener('mouseup', finishResize)
  window.removeEventListener('blur', finishResize)
  // ...
}
```

#### 2.1.3 配套改进

- **函数重命名**：`onMouseMove` → `onDragMove`，`onMouseUp` → `finishResize`，语义更清晰
- **窗口失焦兜底**：新增 `window.addEventListener('blur', finishResize)`，窗口失焦时自动结束拖拽
- **清理逻辑统一**：`onBeforeUnmount` 直接调用 `finishResize()`，避免重复代码
- **防监听器泄漏**：正在拖拽时再次按手柄，先调用 `finishResize()` 收尾上一次

#### 2.1.4 兼容性

Pointer Capture API 在现代浏览器中支持良好（Chrome 55+, Firefox 59+, Safari 13+）。对于不支持的环境，代码自动降级到 document 监听方案。

## 四、技术亮点

### 4.1 Pointer Capture 实战

Pointer Capture API 是解决跨文档上下文事件吞掉问题的标准方案。相比 `postMessage` 通信方案，Pointer Capture 更简洁、性能更好、无需 iframe 配合。

**关键代码模式**：
```typescript
el.setPointerCapture(pointerId)
el.addEventListener('pointermove', handler)
el.addEventListener('pointerup', cleanup)
```

### 4.2 渐进增强与降级

代码对 Pointer Capture 做了特性检测，不支持时自动降级到 document 监听方案，确保兼容性。

### 4.3 函数命名语义化

`onMouseMove` → `onDragMove`，`onMouseUp` → `finishResize`，函数名更准确反映其职责。

### 4.4 清理逻辑统一

`onBeforeUnmount` 直接调用 `finishResize()`，避免重复代码，确保组件卸载时监听器正确移除。

### 4.5 窗口失焦兜底

新增 `window.addEventListener('blur', finishResize)`，防止用户拖拽时切换窗口导致状态卡住。
