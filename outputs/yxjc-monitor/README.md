## 2. 怎么用（复现 / 回归）

```bash
# ① mock ≡ 契约 的一致性判据（唯一可执行的那条）
cd outputs/yxjc-monitor && ruby spec/check-contract-parity.rb   # 期望 exit 0

# ② 契约可解析性 / 0 悬空 $ref：用任意标准 OAS 工具解析 spec/openapi.local.yaml

# ③ 外壳视觉判据：起静态服务指向 web/，用 Playwright 量三列宽与图表 SVG 非空
```

**不要**把本目录当成「当前系统」去覆盖或部署：它是**冻结的试跑快照**，用途是回归比对与判据回查。
