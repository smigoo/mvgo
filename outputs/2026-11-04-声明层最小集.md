## 三、可直接放到项目根的示例

放到**目标项目根**（即 `s0-scan.cjs` 的 `ROOT`），文件名严格 `mvgo.project.json`（L225 硬编码）。

```json
{
  "delivery": {
    "branch": "go-dev"
  },
  "responseEnvelope": {
    "code": "code",
    "message": "message",
    "data": "data",
    "successCode": 200
  },
  "links": {
    "figma": [
      "https://www.figma.com/design/<fileKey>/<name>?node-id=<id>"
    ],
    "apifox": "https://app.apifox.com/project/<projectId>"
  }
}
```

字段说明：
- `delivery.branch`：交付目标分支。取值优先级**三级**（先命中先用）：① 任务高级选项 `deliveryBranch` → ② 本文件 `delivery.branch` → ③ 内置默认 `go-dev`。**任何情况下不落 `main`。** 项目开发者可自行改成别的分支名 —— 这正是它进声明层的原因。
- `responseEnvelope`：字段名映射 + 成功码。样本项目若用 `{status,msg,result}`，就写 `{"code":"status","message":"msg","data":"result"}`。
- `links.*`：外链。`figma` 支持单个字符串或数组（多稿）；`apifox` 允许对象形式带 `projectId`。
- 解析失败不会静默：`s0-scan.cjs:227-230` 捕获 `JSON.parse` 异常后写 `__parseError`，S0 会如实带出。
