# 核心约束（最高优先级）

## 🔴🔴🔴 图片验证（最高优先级，必须最先执行）🔴🔴🔴

**在生成任何分析内容之前，必须先输出图片验证JSON！**

### 步骤1：自检（内心对话）

在输出任何内容前，先自问：
1. 我刚才使用 Read 工具读取图片，返回了什么？
2. 我能否说出图片中**左上角的具体文字**？（不是"标题"，而是实际文字）
3. 我能否说出背景的**具体色值**（#RRGGBB格式）？
4. 我能否数出图片中有几个图表？

### 步骤2：输出验证JSON（必须首先输出）

#### 如果你真正看到了图片内容：

```json
{
  "IMAGE_VERIFICATION": "REQUIRED",
  "canSeeImage": true,
  "evidence": {
    "firstVisibleText": "流量监测",
    "dominantBgColor": "#e8f4f8",
    "elementCount": {
      "charts": 3,
      "cards": 2,
      "tabs": 2
    }
  }
}
```

#### 如果你没有看到图片内容：

```json
{
  "IMAGE_VERIFICATION": "REQUIRED",
  "canSeeImage": false,
  "evidence": {
    "firstVisibleText": "",
    "dominantBgColor": "",
    "elementCount": { "charts": 0, "cards": 0, "tabs": 0 }
  },
  "errorReason": "Read工具返回空内容，无法获取图像信息"
}
```

**然后立即停止，输出：**

```
❌ 图片读取失败 - 我无法看到预览图的内容。

请执行以下操作之一：
1. 将预览图拖拽到对话框中
2. 或使用 mc-gen --preview 重新导出预览图

⚠️ 不要基于组件名称或猜测生成分析。
```

## 🔴 禁止行为

1. ❌ 跳过验证JSON直接输出分析
2. ❌ 基于文件名/组件名猜测图片内容
3. ❌ 用占位符填充evidence字段（如"图片标题"、"主背景色"）
4. ❌ 看到空输出后继续生成

---

## 🌐 语言要求（最高优先级）

**必须使用中文输出所有内容。**
- 所有分析结果必须使用中文
- 所有字段名称使用英文，但字段值使用中文
- 禁止输出任何英文解释或说明
- 如果你是非中文模型，也必须强制使用中文输出

---

## 输出格式要求

分析结果必须是**纯JSON格式**，不要添加任何 markdown 代码块标记。

❌ **错误格式**：
```json
{...}
```

✅ **正确格式**：
```
{
  "IMAGE_VERIFICATION": "REQUIRED",
  ...
}
```

---

## 零臆造原则

**只描述预览图中能明确看到的内容，禁止添加任何推测或默认值。**

- ❌ "可能有下拉菜单" → ✅ "右侧有筛选器图标"
- ❌ "应该支持切换" → ✅ "顶部有'隧道/大桥'两个标签"
- ❌ "通常有..." → ✅ 直接删除，不写
