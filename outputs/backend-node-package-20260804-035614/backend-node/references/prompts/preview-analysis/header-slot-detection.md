# 头部插槽检测规则

## 目标

检测预览图中面板标题行是否存在插槽控件，为后续Figma节点验证提供候选列表。

## 插槽类型定义

| 插槽类型 | 控件类型 | 视觉特征 | 位置 |
|---------|---------|---------|------|
| `header-right` | 统计指标 | 数字+单位，小卡片样式 | 标题右侧 |
| `header-right` | Tab切换 | 小型Tab/分段控件（2-4个选项，宽度<150px） | 标题右侧 |
| `header-right` | 图标操作 | 单个或多个图标按钮 | 标题右侧 |
| `title-left` | 状态标识 | 小图标/角标/状态点 | 标题左侧 |
| `title-right` | 辅助文字 | 小号文字说明（更新时间/单位等） | 标题文字右侧 |

## 核心判断规则

⚠️ **关键原则**：只有**与面板标题文字在同一水平线上**的控件才是插槽候选。

### 判断流程

1. **定位面板标题**：找到预览图最顶部的文字标题（如"监测预警"）
2. **确定标题行范围**：标题文字上下±15px的区域
3. **识别同行控件**：在标题行范围内的功能性控件

### 排除规则（重要）

以下元素**不是**头部插槽：

- ❌ 在标题行**下方**的任何元素（即使看起来在组件顶部）
- ❌ 大型Tab控件（宽度>150px或选项>4个）→ 这些是内容区筛选Tab
- ❌ 占据整行的筛选条或导航栏
- ❌ 在渐变横幅下方的元素（属于内容区）
- ❌ 装饰性图标（如右上角的装饰元素，通常在内容区第一行）

## 输出格式

在preview-analysis的JSON输出中添加`headerSlots`字段：

```json
{
  "headerSlots": [
    {
      "slotType": "header-right",
      "controlType": "统计指标",
      "description": "3个数字指标卡片",
      "confidence": "high"
    },
    {
      "slotType": "header-right",
      "controlType": "Tab切换",
      "description": "列表/图表 两个选项",
      "confidence": "high"
    }
  ]
}
```

**字段说明**：
- `slotType`: 插槽位置（header-right/title-left/title-right）
- `controlType`: 控件类型（统计指标/Tab切换/图标操作/状态标识/辅助文字）
- `description`: 简短描述（帮助后续Figma节点匹配）
- `confidence`: 置信度（high/medium/low）

## 常见错误示例

❌ **错误**：将内容区顶部的数据筛选Tab识别为header-right
```
[面板标题]                    ← 标题行
━━━━━━━━━━━━━━━━━━━━━━━━━
[全部][桥梁][边坡]             ← 内容区第一行（不是插槽！）
```

✅ **正确**：只识别与标题同行的小型Tab
```
[面板标题]    [列表][图表]    ← 同一行，是插槽✅
━━━━━━━━━━━━━━━━━━━━━━━━━
[内容区...]
```

## 检测要点

1. **位置优先**：先判断位置（是否同行），再判断类型
2. **尺寸特征**：头部插槽通常较小、紧凑
3. **功能性**：插槽是功能性控件，不是装饰元素
4. **保守原则**：不确定时不输出，避免误判
