# Header Relation 判断规则

## 什么是 headerRelation？

`headerRelation` 描述 section 内部的**标题与内容的空间关系**，直接影响代码生成的 template 结构。

## 5 种取值及判断流程

```
┌─────────────────────────────────────────────┐
│           headerRelation 判断流程             │
├─────────────────────────────────────────────┤
│                                             │
│  1. 这个 section 有可见的标题文字吗？         │
│     ├─ 没有 → "no-header"                   │
│     │                                       │
│     └─ 有 ↓                                 │
│                                             │
│  2. 标题和主要内容在同一水平行吗？            │
│     ├─ 是（左右排列）                        │
│     │   └─ "title-same-row"                │
│     │      + 必须填写 slotCandidate          │
│     │                                       │
│     └─ 否（上下排列）↓                       │
│                                             │
│  3. 标题下方有实质性的内容区域吗？            │
│     ├─ 只有标题，没有内容 → "header-only"    │
│     │                                       │
│     └─ 有内容区域 → "content-below-title"   │
│                                             │
│  4. (特殊) 整个 section 就是 header →        │
│      "header-only"                          │
│                                             │
└─────────────────────────────────────────────┘
```

## 各取值详细说明

### content-below-title（最常见）
```
┌──────────────────────────┐
│ 📊 环境监测数据    [🔄][⋮] │ ← header 行（标题 + controls）
├──────────────────────────┤
│                          │
│   ┌──────────────────┐   │
│   │   图表区域        │   │ ← body（内容在标题下方）
│   └──────────────────┘   │
│                          │
└──────────────────────────┘
```
- `slotCandidate`: `null`（不需要插槽）

### title-same-row
```
┌──────────────────────────────────────┐
│ 环境监测  │  [CO₂] [能见度] [照明] [通风] │ ← 标题和控件在同一行
├──────────────────────────────────────┤
│                                      │
│            图表区域                  │
│                                      │
└──────────────────────────────────────┘
```
- `slotCandidate`: 必须指定（如 `"tab-bar"` 或 `"filter-bar"`）

### no-header
```
┌──────────────────────────┐
│                          │
│      （无标题，直接内容）   │
│                          │
└──────────────────────────┘
```
- `slotCandidate`: `null`

### header-only
```
┌──────────────────────────┐
│   📋 数据统计概览         │ ← 只有标题行
└──────────────────────────┘
```
- `slotCandidate`: `null`

## header.controls 填写规则

当 headerRelation != "no-header" 时，检查标题行的**右侧**是否有控件：

```json
{
  "header": {
    "title": "环境监测",
    "controls": [
      { "type": "icon-button", "icon": "refresh", "label": "刷新" },
      { "type": "icon-button", "icon": "more", "label": "更多" }
    ]
  }
}
```

**常见错误**：
- ❌ `controls: []` — 当图像中 clearly 有按钮时（这是当前最常见的缺陷！）
- ✅ 仔细观察每个 panel 标题栏右侧，哪怕是很小的图标也要报告
