# Figma 管线助手 v2

> **智能整理 + 管线映射 + 合规检查** 一体化插件
> 基于 TidyUp 能力 + 管线约定，一键完成设计稿整理

## 核心能力

### Stage 1: 智能整理（TidyUp 能力）
自动识别节点角色并重命名，基于结构/属性/内容推断：

| 角色 | 识别规则 | 命名示例 |
|------|---------|---------|
| 背景 | 图片填充 或 大尺寸纯色矩形 | `bg-header` |
| 图标 | 矢量图形 或 ≤32px 组件 | `icon-search` |
| 按钮 | 小圆角 Auto Layout + 文字 | `btn-提交` |
| 标题 | ≥24px 文字 | `heading-标题` |
| 正文 | 普通文字 | `text-内容` |
| 容器 | 有子元素的 Frame | `section-区块` |

**自动排序**：按阅读顺序（Y→X），背景沉底
**垃圾清理**：空 Frame、0x0 节点、画布外元素

### Stage 2: 管线映射
将通用命名映射为管线约定：

| 通用命名 | 管线约定 |
|---------|---------|
| 根容器无意义命名 | `cp-component-xxxx` |
| 含柱状图特征的 Frame | `@echarts/bar-xxxx` |
| Stage 1 生成的 `bg-*` | 保留（已符合规范） |
| Stage 1 生成的 `icon-*` | 保留（已符合规范） |

### Stage 3: 合规检查
检查项分级（同 v1）：

| 级别 | 检查项 | 不修复后果 |
|------|-------|-----------|
| ❌ Error | 根容器命名、根容器 Auto Layout | 生成失败/布局重叠 |
| ⚠️ Warning | 背景图/图标命名、图表标记 | 资源丢失/资源爆炸 |
| 💡 Info | 按钮/Tab 命名 | 代码可读性略降 |

## 安装方法

1. 打开 Figma → 菜单 → 开发 → 开发插件
2. 点击「导入插件」
3. 选择 `naming-checker-v2/manifest.json`
4. 插件安装完成

## 使用方法

### 方式一：一键整理 + 检查（推荐）
1. 选中要整理的 Frame（不选中则处理整个页面）
2. 运行插件 → 点击 **「🛠️ 一键整理 + 检查」**
3. 查看结果，Error 级别需手动修复

### 方式二：分步操作
1. **「🧹 智能整理」** → 自动重命名 + 排序 + 清理
2. **「🔍 合规检查」** → 检查管线规范
3. 根据检查结果手动修复剩余问题

## 注意事项

- **所有操作可撤销**：Cmd+Z / Ctrl+Z 完全回滚
- **锁定层安全**：锁定节点不会被修改
- **组件实例保留**：设计系统组件名不被覆盖
- **离线运行**：无网络请求，数据不出本机

## 技术实现

- **角色检测**：基于节点类型、尺寸、填充、子元素结构的多维推断
- **排序算法**：Y 轴优先（阅读顺序），背景沉底
- **清理策略**：空 Frame、0x0 节点、画布外元素（可配置）
- **管线映射**：正则匹配 + 特征检测（柱状图窄矩形等）
