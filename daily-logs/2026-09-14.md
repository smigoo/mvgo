## 刀 16b：LESS 颜色函数实参的合成值必须可求值（已闭环）

提交 **`e5f9bcb`**（10 文件 +647/−55）。子仓 `backend-node`。

### 症状与根因

与刀 15 **报错逐字相同** —— `Error evaluating function \`lighten\`: Argument cannot be evaluated to a color`
—— 但产物里**一个 `var(--` 都没有**。按刀 15 的路径图去查会一无所获。

真根因：`lighten()` 只要求「实参**可求值为颜色**」。除 `var()` 外，**按名字猜值的合成器**产出的值同样不可求值：

| 产出 | 例 | 命中的名字分支 |
|---|---|---|
| `unset`（兜底） | `@hint-strong` | 无关键词命中 |
| `8px` | `@radius-x` | `/radius/` |
| `1` | `@line-alpha` | `/(opacity\|alpha)/` |
| `1.5` / `400` / `0.2s` | `@lh-x` / `@weight-x` / `@delay-x` | 各自关键词 |

**核心认知：只看变量名永远不够** —— 名字分支会理直气壮给出 `8px`。「是不是颜色」**只有消费端知道**。
（这刷新了刀 15 的表述：不是「var() 与 lighten() 冲突」，而是「**不可求值的值**与 lighten() 冲突」，var() 只是其中一类。）

### 治本

1. **抽出事实源** `src/ai-engine/utils/less-color-funcs.js`（原本私有在 `code-healer.js` 里）：
   `LESS_COLOR_FUNCS`(13) / `isColorEvaluable` / `isUsedByLessColorFn` / `collectColorFnVars` / `NEUTRAL_LESS_COLOR='#333333'`。
   踩坑：`isColorEvaluable` 若用 `/^[a-z]+$/` 放行具名色，会**连带放行 `unset`/`inherit`** → 必须**只认**合成器会产出的形态（`#hex`/`rgb*()`/`hsl*()`/`hsv*()`）。
2. **规则：消费端事实优先于名字猜测**。`safeLessVarValue(name, ctx)` 做**后置过滤**（不是前置 early-return，否则丢掉名字分支更优的猜测）：
   ```js
   const guess = guessLessVarValueByName(n);
   if (!isColorEvaluable(guess) && isColorFnConsumer(n, ctx)) return NEUTRAL_LESS_COLOR;
   return guess;
   ```
   `ctx` 两条供给路径：`{styleText}` 现场推断 / `{usedByColorFn}` 集合查表；**拿不到 ctx 时退化为原行为**（不制造无关变更）。
3. **穷举「取值路径」逐条收口**（刀 15 教训：只修两条不够）。判据命令
   `grep -rnE '@\$\{[^}]+\}: \$\{' src/ --include="*.js" | grep -v '\.spec\.'` → 共 **4 条真实路径**：

| # | 位置 | 处置 |
|---|---|---|
| ① | `file-writer#safeLessVarValue`（3 处调用） | 传 `styleBlocks` |
| ② | `resource-mounter` 臆造变量补全 | 传 `styleNow` |
| ③ | `less-variable-checker` 优先级 1/2/3 | 扫描期 `collectColorFnVars` 收集；优先级 2 传 `{usedByColorFn}`；命中颜色函数实参仍落 `uninferredVariables` 告警 |
| ④ | `code-healer#injectThemeVarDeclsForLess` | 注的是 theme **原样值**（可能是 `var()`）→ 被颜色函数引用时换中立色；**非**颜色函数引用者照旧原样注入（**保 M5-6 的 `@fontSize: var(--fontSize)`**） |

- ④ 最阴：其注释写着「值必须原样取自 theme-vars」，看起来**不该动**。
- 残余（已知未收口）：`style-tokens#buildVue3ThemeMixinSnippet` / `mc-skeleton#tokensToLessVars` 构造 theme 文件本身，消费方是「任意组件」→ 本地拿不到消费端事实；但输入是设计稿实测色（构造即真颜色）。
- `less-variable-checker` 的 `warnings` 语义：颜色函数实参兜底色是**猜的** → 必须仍落告警，不能因「不再是 unset」而静默通过。

→ 保守规则「**仅当完全没有 display 时才补**」覆盖 100% 观测场景，且不覆盖作者显式意图。
