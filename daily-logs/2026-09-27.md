## 🔎 「一片蓝」循环追问（用户：修好一点→再修→每次都回到一片蓝，哪里有问题？）
### 结论：**不是循环 bug，而是两条「上游事实源」每次生成都重复施加同一错误模式**
我们之前所有修复都在**下游**（R5/主题/布局/产物形态）→ 动不了上游 → 每次重生成回到同一状态 = 用户感知的"错误循环"。

### 根因 A：真值表 `section-tree.js#buildSectionStyleFacts`（每次生成注入）三处确定性缺陷
用真机数据（bd4f69db 的 plan+figma）实调取证：
1. **把图元节点当"内部元素样式真值"**：输出里有 `circle → bg:#000000`、`path → bg:#559eff`、
   `Rectangle 346241415 → bg:linear-gradient(#93ccff)`、`Rectangle 346241414 → bg:linear-gradient(#2b9bff,#299aff)`、
   `Vector → bg:linear-gradient(rgba(71,166,250,0.4)…)`、无名的 `bg → bg:linear-gradient(#85baff,#bfe2ff)`。
   → 产物里 `.c-device-monitor-active-bg { background: linear-gradient(180deg,#2b9bff,#299aff) }` **与 `Rectangle 346241414` 的值逐字对应**
   ⇒ 模型是**照抄真值表里的图元渐变**，不是臆造。
2. **文字行出现 `color:linear-gradient(...)`**：`设备监测 → 文字「设备监测」color:linear-gradient(180deg,#1990ff,#5a7eff)`
   → 语义错误（渐变不可能是文字色），模型只能瞎猜。
