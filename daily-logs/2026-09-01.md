## W3 · W2 落地后的防御性自查：注入声明撞名防护（2026-09-01 14:10，commit `d290bfd`）

**性质**：不是新事故，是 W2 上线后主动做的防御性审计挖出的隐患。

### 隐患机制
W2 让「同一资源可声明多个名字」（主名 import + `const 别名 = 主名`），**声明点从 1 个/资源涨到 N 个/资源**，
撞名概率随声明点数量上升。而 `injectResourceImports` 的既有去重预处理只清两种形态：
`import X from` 与 `const|let X =`（正则 `^\s*(?:const|let)\s+${v}\s*=`）。**漏网 4 类**：

| # | 漏网形态 | 为什么正则清不掉 |
|---|---------|-----------------|
| ① | `const { bgtabActive } = defineProps(...)` | 解构，`{` 挡在 `const` 与名字之间 |
| ② | `let bgtabActive;` | 正则要求 `=`，无赋值不匹配 |
| ③ | `var bgtabActive = 1` | 正则只写了 `const\|let`，漏 `var` |
| ④ | `const a = 1, bgtabActive = 2` | 多声明符，只清首个 |

任一漏网 + 注入的 `const 别名 = 主名` → **重复声明 → SyntaxError**。
**比原 bug 更糟**：原 B 是单个资源静默 undefined，这是**整块 SFC 编译失败**。

### 修复（2 处，同一根因的正反两面）
1. **`collectDeclaredBindings` 扩大识别面**（`resource-import-guard.js:146`）：
   捕获到语句尾（`;` 或行尾）后按逗号切声明符 → 兼容解构 / 裸声明 / 多声明符。
   要求标识符后紧跟 `=`|`;`|结束，**过滤 `const s = 'a, b'` 字符串内逗号造成的误判**。
2. **注入前撞名复核**（`:391`）：`survivedDecls = collectDeclaredBindings(cleanedCode)`，
   过滤 `imports` / `aliasDecls`，**仍被声明的名字一律不再注入**（保留 LLM 自己的声明）。
   主名 import 一并在保护范围内 —— 该类撞名在 W2 之前就已存在，属同族隐患，一并修掉。

> ⚠️ 该函数还被 W1 `healUnavailableResourceRefs` 用作「已声明 → 视为业务变量，不剔除」的判据。
> 扩大识别面会让 W1 **更保守**（少剔除），所以必须重跑事故 5 端到端复测 —— 已验证无回归。

### 验证

## ⭐ P1-Slice2：定位并修复「之前的不见了」的真实根因 —— 候选快照回退（23:30）

### 根因（P0.5，比 4 个磁盘覆盖点更优先）
`microcode-engineer.js:1188-1199`（改前）与 `vue3-engineer.js:440` 的 chunk 级推送：
- **推送**在 `runChunk` **内部**：`{ ...allFiles, ...res.files }`（**调用时刻求值**）
- **合并** `Object.assign(allFiles, res.files)` 却在 `runChunk` **外部**（1330/1367/…）
- 两者之间隔着 `await` 边界，而子组件是**并行**生成的（`genSubComponents`，并发 2~3）

交错时序：worker A 推送 `{A}` → worker B 推送 `{B}`（A 尚未合并进 allFiles）→
caller 才 Object.assign。`phase2.service.ts:614-686` 的 `createCandidate` **每次都把
候选指针指向最新 revision** → 预览从「含 A」回退成「只剩 B」。

**关键认知**：磁盘覆盖层影响的是「最终产物是否正确」（可恢复）；
快照层影响的是「用户生成过程中看到什么」（体验直接受损）。**痛点在快照层，不在磁盘层**。

### 修复
新建 `microcode/chunk-snapshot-pusher.js` → `pushChunkSnapshot({ allFiles, resFiles, onFilesReady, stage, logger })`：
**① 先 `Object.assign(allFiles, resFiles)` → ② 再推送 `{ ...allFiles }`**（累积全量）。
附加保守规则：`resFiles` 为空**不推送**（不用不完整快照顶指针）；`onFilesReady` 抛错**不阻断**（仅 warn，产物已合并不丢）。
接线 `microcode-engineer.js:1195` + `vue3-engineer.js:446`；旧模式残留 grep = 0。
