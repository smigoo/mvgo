## 技术洞察

### temperature 透传链路
```
前端配置 → workflow.service.ts (resolveVisionConfig/resolveTextConfig)
         → ai-defaults.js (读取 temperature 并设置到 primary.temperature)
         → 供应商池 resolveProvider (透传 temperature)
         → VisionAgent/VisionParser/VisionComparator (必须传递 temperature)
         → normalizeRequestTemperature (归一化)
         → LLM 请求
```

关键发现：虽然 `ai-defaults.js` 正确设置了 temperature，但构造 VisionAgent 时没有传递，导致整个链路的最后一环断裂。
