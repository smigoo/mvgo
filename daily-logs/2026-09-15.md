# 追查（14:23）：tab-item 真值无填充，产物为何出现背景？

# 追查 2（14:25）：tabs-list 已有 bg 图，为何还要 bg 渐变色？——**不需要，且信息更差**

## Figma 真值（类型事实）

⇒ 历史注释里「两端圆弧丢失」正是此丢失清单的第 2/3 项。

① 同一视觉两条落地路径（图片 + CSS）→ 必然冲突；② CSS 版不透明 → **盖住本该显示的图片**（4 个 tab-item 各盖一份）；

### 「为什么会臆造」的机制归因（非道德归因，2026-09-15 21:12）
1. **LLM 是概率补全器不是抄录器**：输出空间是开放代码，任何缺口默认用先验填满；「不生成」不是默认行为。
2. **否定性约束天然弱于肯定性约束**：「这里没有饼图」需要主动维持抑制，而「这里有个饼图」有直接信号 → 抑制比照做难。
3. **注意力稀释**：`charts[]` 几百字淹没在 67 万字节 figma.json 格式化输出 + layoutStructure + elementStyleMap +
   资源清单里。事实权重 ∝ 显著性，不 ∝ 真理性。
4. **强先验压过弱事实**：「柱状图+双系列」激活训练数据里全球 BI 默认蓝红对比色；一行色值约束打不过模板化先验。
5. **两个概率模型串联**（vision → engineer）：误差乘性。「要求一个概率模型忠实于另一个概率模型的输出」= 幻觉对幻觉。
   本例 `#ff7875` 就是 vision 造的（figma 全树无此色）。
6. **拆分放大稀释**：本任务拆 8 个子组件 → `charts[]` 每次调用被稀释一遍，每次只负责 1/8，**没人完整负责饼图**。

### 「四层手段强度谱」（可复用方法论）
| 层 | 手段 | 失效模型 | 本仓落点 |
|---|---|---|---|
| 1 要求 | prompt 文本软约束 | 靠模型自觉，概率泄漏 | `no-hallucination.md`（已有，无效） |
| 2 校验 | 事后门禁 + 重试 | 方向单一 + 只读 index.vue | `do-not-invent-validator`（已失效） |
| 3 强制 | schema 回填（输出必须含事实字段） | 错误无法表达 | **未做** |
| 4 消除 | assembler 确定性接管 | 事前不可能 | `color-assembler`(6-B) / chart-builder **未做** |

**核心判据**：_不要试图让 LLM「不做某事」（抑制），要让它「没有机会做」（消除）。_
凡有唯一正确答案的（色值、布局比例、图表结构）→ 不让 LLM 生成，只让它「选择/填空」。
**能确定算的绝不过 VLM**：`seriesColors` 可从 figma fills 直接提取（实测全树有蓝系 5 色），
让 VLM 提供色值 = 主动引入一次幻觉机会。
**每右移一级 → 删掉左边那一级的纠偏器**（删减法收敛）。顺序 = 能消除的消除，剩下不能消除的才加门禁。

## 高度比例管线双 bug 治本（2026-09-15 晚 · c-device-monitor-44384241 实锤）

### 现象
