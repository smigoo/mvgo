### 一、打包阶段

**坑1：zip 解压后多嵌套一层 dist（dist/dist/ 或 mvgo/dist/index.html）**
- 根因：macOS Finder 压缩会带 `__MACOSX` 元数据 + 多一层目录；或从 dist 父目录打包（zip 内含 dist/ 前缀）。
- 解决：必须在 dist **内部**打包。
  - 前端：`cd frontend/dist && zip -qr ../../dist.zip .`
  - 后端：`cd backend-node && zip -qr ../backend-lite.zip package.json dist/`
- 解压后若仍嵌套：`cd mvgo && [ -d dist ] && mv dist/* . && rmdir dist`

**坑2：scp 大文件（>90MB）传输损坏**
- 现象：`End-of-central-directory signature not found` / `cannot find zipfile directory`
- 根因：scp 传大文件不稳定（网络抖动截断），unzip 校验失败。
- 解决：
  - 后端拆成 **1.4MB 小包**（只含 `package.json + dist`，不含 node_modules）→ 稳定。
  - 前端 90MB 仍易损，优先用 `rsync -avP`（断点续传）；或 `split -b 20m` 分片后 `cat` 合并。
  - 本次前端最终由用户手动 scp 传成功（重试后通过）。

### 二、后端启动

**坑3：`.start-server.sh` 是 macOS 脚本，ECS 上不可用**
- 现象：`bash .start-server.sh: No such file or directory`（脚本引用 `/Users/smigoo/.workbuddy/binaries/node/`）。

**坑4：缺 node_modules → `Cannot find module 'dotenv/config'`**

**坑5：dist 结构嵌套** → `mv dist/* . && mv dist/.* . 2>/dev/null; rmdir dist`

**坑6（核心）：`.env` 缺失导致 502 / 401**

- **完整 `.env` 模板（ECS 必须存在）**：
  ```
  NODE_ENV=production
  MONGODB_URI=mongodb://root:Microvideo%402026@dds-bp13ae3414783164.mongodb.rds.aliyuncs.com:3717/langgraph-server?replicaSet=mgset-102332332&authSource=admin
  ```

- **关键**：`dotenv/config` 在部分 main.js 配置下读不到 .env，必须用 `set -a && source .env && set +a` 显式注入。
