## 修复 Vue3 Max 预览报 "Cannot use 'import.meta' outside a module"（15:28-15:45）

- **兼容性**：不改生成器、不改组件源码（保持标准 Vite/ESM 写法，真实 Vite 构建时 import.meta.url 原生可用）；对已有/未来组件一律生效。图片端点确认：dev `/__raw` 返回 `image/png` 等、prod `/api/preview` 用 `res.sendFile` 自动 content-type，均正常。

## 微码/Vue3 预览「样式层特殊处理」兜底（15:5x）
- **需求澄清（经用户纠正后修正）**：微码内容根节点不要做头部/背景/padding/阴影（面板外壳由宿主 `<base-panel>` 提供）。**Vue3 不是"纯组件不套面板"——Vue3 组件自身完整还原了面板外壳**（背景色/图、header、padding、外框阴影都直接写在 SFC 根节点上，如 `.dashboard-container{background;padding;min-height:100vh}` / `.container > header`，且**所有 Vue3 组件都不使用 `<base-panel>`**）。Vue3 的"面板"是组件自己写的，所以尺寸=组件自身（含面板）实际尺寸，且预览中绝不能对其根节点做 reset（否则会把面板背景/padding 干掉）。

  - ✅ 能：padding / 阴影 / 边框 / 外边距 / 背景 写在**内容根节点**上的，可以用 CSS 精确兜底（reset 根节点即可，安全不误伤内容子元素）。
