## components.vue CTA 按钮「没效果」排查（RippleButton + :deep(.cta)）
- **现象**：用户多次反馈 RippleButton（涟漪）效果"没生效/没看到"。
- **根因一（外观）**：`.cta` 样式写在 components.vue 的 `<style scoped>` 中，但 CTA 已改为 `<RippleButton class="cta">` 子组件。scoped 选择器编译为 `.cta[data-v-xxx]`，而 RippleButton 内部 `<button>` 无父 scope id → **绿色渐变/阴影/hover 全部失效**，按钮像裸按钮。修复：所有 `.cta` 系列改成 `:deep(.cta)`（`[data-v-xxx] .cta` 穿透到子组件）。已 curl 编译产物确认选择器正确生成；已 `POST /__invalidate` 清 Vite 缓存。
- **根因二（交互，更关键）**：在「上传截图」模式下 `canGo = images.length === 1`，未上传截图时 `:disabled="submitting || (!canGo && !busy)"` 为 true → 按钮 `disabled`。而 RippleButton 的 `handleClick` 在 `props.disabled` 时 `return`，**不创建涟漪、不 emit click** → 用户点下去完全没反应、看不到任何效果。这是预期行为并非组件损坏，但极易被误判为"没效果"。
- **结论**：用户看到的"没效果"几乎总是因为**未上传截图导致按钮 disabled**。上传截图（或 Figma 模式填好链接+确认预览图）后按钮 enabled，点击即从点击点扩散蓝色涟漪（go() 的 submitting=true 在 emit click 之后才设，涟漪已 push 进 DOM 会正常播放）。
- **排查经验**：改完 scoped 样式后若页面"没变"，先 `curl POST /__invalidate` + 浏览器硬刷新；Inspira 这类复制粘贴组件库的样式若用父组件 `<style scoped>` 通过 `class` 传入子组件，必须用 `:deep()` 才能穿透。
