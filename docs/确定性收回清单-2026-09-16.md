## 四、核心结论

**17 项确定性事实里，已收回 13 项（布局、资源、图表、格式、类名骨架、componentId、header 归属七块基本闭环），剩 4 项集中在两类：**

1. **命名（A2/A4）**：componentId 和事件名仍是「双前缀/事件双轨」源头。
2. **结构（E1/E2/E3）**：header 归属、section 去重、骨架装配。

**收敛路径**：先啃 A2（componentId，命名最根本，止住「双前缀/事件双轨」），再 E2（header，R3 补齐），最后 E1/E3 收尾。

**每收回一项，必须同时删掉对应纠偏器**，否则就是「补丁 + 接管」并存，复杂度不降反升——这是「删减法」的铁律，也是回答「为什么管线越修越复杂」的解药。

## 五、对冲式治理铁律（2026-09-22 · mc-1790058609462 血泪）

**教训**：grid 列数治理曾走「对冲式」弯路——`nodeLayoutFacts.decideGeometricLayout` 的 side-by-side 比例判据把 3×4 网格系统性误判 column（网格里同行卡相邻才算 side-by-side，跨行都算堆叠，比例天然偏低），于是加了 `itemFacts.detectGridColumns` 去对冲，两个几何推断结论相反，靠「2.12 在 2.11 后执行」碰巧压对。用户一句「会不会前后矛盾」逼出根因。

**铁律（整改时必须自检）**：
1. **单一事实源**：一个确定性事实只允许一个来源；几何推断出 bug 就修在源头（`decideGeometricLayout`），禁止加对冲层。
2. **几何聚类优先**：均匀网格（x 聚类均匀列）必须先于 side-by-side 比例判据——比例判据对网格、文本纵排等「跨行/跨列」布局天然失效。
3. **事前约束 > 事后纠正**：prompt 骨架约束（planner itemSkeleton）是首选，事实注入（LAYOUT-FACTS-INJECT 单一链路）是兜底，事后 patch 是最后手段。
4. **删减法**：每收敛一个事实源，必须删掉对冲层——本次已删 `item-facts-injector` 的 grid 通道 C + `setContainerGrid`（含清 gap bug）+ `figma-item-facts` 的 grid 字段，门禁总量不增反降。

**整改分层（2026-09-22 定）**：
- P0 ✅ 已做：grid 单一来源（G1）
- P1 🟡：icon 尺寸 + 卡内文本方向统一到「item 级布局事实」模块，与 nodeLayoutFacts 职责边界显式化
- P2 🟡：H3 卡内完整骨架（LLM 零自由发挥 → 删 item-facts-injector 事后注入）
- P3 ⚪：A1 类名骨架化收尾 + D 图表消除层（injectEchartsFallback 按视觉真值生成 type/series）

### 7.2 问题①：`::before` vs 父元素 CSS background —— **由「几何相等性」决定，非取舍**

**结论**：不是哪种更合理，而是背景层与宿主 **box 是否相等**：
- **相等**（容器/卡片/根的全尺寸背景）→ **必须挂父元素/宿主 CSS background**。这是项目铁律「背景必须挂在承载内容的元素上，禁止 `-bg` 空壳 DOM」的正解：DOM 零冗余、语义直白、可被主题变量/JS 驱动。B1 上移、B11 资源挂载均走此路。
- **不相等**（Figma 矢量装饰：缩窄渐变条、描边块、偏移定位）→ **只能 `::before`**。合并进宿主 background 会丢几何；保留 DOM 空壳违铁律 → `::before` 是唯一「几何 1:1 + DOM 零空壳」形态（B2/B3）。
- **资源图（真背景）永远挂宿主 inline/HOST CSS，绝不用 `::before`**；`::before` 只承载「无法表达为宿主背景」的装饰几何。
- ⚠️ `::before` 代价：需宿主 `position:relative`（否则逃逸 → 实测「一片蓝」）；`content:''`+z-index 可能盖内容；JS 不可寻址；B3 的几何是**合成的**（见 7.3）。

### 7.3 问题②：硬编码审计 —— **3 处真实违规 + 2 处需标注，其余全部零硬编码**

- ❌ **B3**(1867)：P-10 合成几何常量 `6px/34px`（来自某具体组件的实测）——**最需治**。死规则缺 position 时使用 → 换组件必错位。
- ❌ **B16**(2339)：P-12b `gap:4px`+`align-items:center`，且判据是错误启发式（「相邻标签即父子」），**仍在 POLISH 阶段活跃**。
- ❌ **B17**(1667)：vue3 N3 硬编码 `position:'0px 0px'`、兜底 `'100% 100%'`，与 B11 的几何推断**不同源**。
- ⚠️ **B15**(1109)：真值全缺时的**最后兜底**渐变色（可接受，应显式标注 last-resort）。
- ⚠️ **B7**：补的是**字面默认**（如 `cover/center`），非几何真值——属「属性补全」非「值臆造」，可接受。
- ✅ 其余（B1/B2/B4/B5/B6/B9/B10/B11/B12/B13/B14）判据均基于 **属性 / 几何 / 事实链**，按结构特征识别（不按组件名），**跨组件类型通用**。
