# 《感智晓界工坊平台-前端开发使用培训》培训方案

## 课程基本信息

- **课程名称**：《感智晓界工坊平台-前端开发使用培训》
- **培训时长 / 形式**：1.5 小时（线下培训 + 远程接入，需投屏）
- **培训时间**：2026 年 9 月 4 日 18:30–20:00（周五）
- **培训地点**：南京市栖霞区紫东国际创意园 D 区 18 栋 感动科技 4 楼培训教室
- **形式说明**：现场投屏演示；外地前端开发工程师远程参加（实操环节远程学员在各自浏览器跟随平台操作）

---

## 一、培训目的

1. **掌握平台核心使用流程**：配置模型池、配置三方工具；理解并实操"统一生成 → 在线迭代 → 一键交付"的闭环，从设计稿 / 需求直接生成前端业务组件。
2. **提升前端交付效率**：用 Figma 链接、页面 / 组件截图、需求文档等多类输入驱动组件生成，减少重复性样式还原工作。
3. **统一团队组件规范**：生成的组件遵循 Vue3 / 微码组件规范，并兼容后期一体化组件开发。沉淀到团队共享库，降低跨人风格不一致。
4. **打通交付链路**：学会在平台对接真实接口，组件在线编辑、与大模型交互修改、一键推送 Git，让生成物从"演示"变成"可用"。

## 三、培训课程大纲（共约 118 分钟，模块 1 扩充理论后偏长；可压缩答疑至 10 min 拉回 105）

1. **平台基础理论与配置培训（约 38 分钟）**：
先澄清一个关键问题——为什么要在平台统一生成，而不是在自己项目里用 Cursor / Copilot 等本地 AI：本地 AI 是"个人提效工具"，平台是"组织生产能力"；前者帮一个人写得快，但产出风格不一、资产散落各人仓库、会话即逝；后者强制 Vue3 / 微码规范、沉淀共享组件库、交付闭环一站完成，且经评分反哺越用越聪明。随后解读"统一生成 → 在线迭代 → 一键交付"的平台理念，并用一页"平台基础架构（简单说明）"讲清平台四层组成（接入与输入层 / 生成引擎层 Node 后端 LangGraph 多智能体 / 工作台与预览层 Playground+沙盒 / 底座与交付层 共享组件库+GitLab+MongoDB+Java 业务后端），建立整体认知后，再用"传统前端开发全景"拆解前端 7 类工作（视觉还原 / 组件开发 / 数据对接 / 工程化 / 联调自测 / 文档交付 / 性能体验）与各阶段 AI 提效点，再对比"个人项目 / 团队项目 / 平台"三种使用方式与优缺点。重点讲解模型资源池配置（多 Key / 调度）与三方工具接入（Figma 连接器、APIFOX MCP、GitLab、公司 Skills 管理）及模型选择建议，区分完整生成与 Lite 快速生成的适用边界与避坑；澄清核心概念地图（微码 / Vue3 / 一体化组件的区别与选型）；详解质量门禁（L0-B）查什么、怎么看行列级报错、怎么改、不合格也能强制预览；说明在线迭代能力边界与快照/回滚机制；并交代数据安全与资产归属。额外如实说明微码组件对初学者的学习成本（declare / css-vars / 事件 / 业务配置），并点明微码本质为高复用——人工赶交付常不做配置化，而 AI 生成可顺手补齐基础配置能力（兼容一体化的 em、微码深浅主题色、动态背景图、tab 入参），降低门槛同时提升复用。并专门区分本平台与公司 MVP154《提示词工程》课程的本质不同：MVP154 是「串型单智能体」范式（人写好 prompt、单一 LLM 顺序执行、质量取决于 prompt），本平台是「同步 + 对抗的多智能体」协同（LangGraph 编排，视觉解析/布局审查/样式映射同步推进，adversarial-checker 挑刺、self-optimizer 自我优化、leader-developer-reviewer 三角分工），质量门禁即对抗协同的硬落地；学员无需像 MVP154 那样精调 prompt，只给业务输入 + 验收产物。并介绍 Playground（平台内置 VS Code 风格 IDE，Monaco 编辑器带格式化与行号，支持基于 LangGraph 的 AI 对话式组件修改器，自然语言即可改微码组件）与沙盒概念（生成组件在隔离沙盒 vue3-sfc-loader 渲染预览，与宿主/生产物理隔离，改坏不污染不崩平台，是强制预览与快照回滚能安全试错的基础）。最后简要介绍平台演进方向（管线可自定义、大模型路由降成本、后端代码生成、多规范扩展、接入公司 Skills / MCP 生态互通、数据飞轮自我进化），帮助学员建立"平台化、规范化生成"的标准化思维，理解平台长期价值与自身沉淀资产的持续增值。

2. **平台实操与业务场景实战培训（约 50 分钟）**：
重点依托感智晓界工坊平台完成前端业务组件生成全流程：使用 Figma URL 生成完整微码 / Vue3 业务组件；以页面 / 组件截图生成 Lite 版；在线编辑并结合大模型交互迭代；通过 APIFOX 对接真实接口、以需求文档 / HTML 大屏拆分驱动生成；经质量门禁后一键推送 Git。远程学员同步在浏览器实操，补齐"从设计稿到可交付业务组件"的落地能力。

3. **实操答疑与案例互动讨论环节（约 15 分钟）**：
围绕 Figma 还原度不足、Lite 适用边界、组件规范冲突（Vue3 / 微码 / 一体化兼容）、接口对接失败、Git 推送门禁、一体化组件路线等现场常见问题进行分析与互动讨论。

4. **平台计划讨论（约 15 分钟）**：
围绕平台演进方向（管线可自定义、大模型路由降成本、后端代码生成、多规范扩展、接入公司 Skills / MCP 生态互通、数据飞轮自我进化）与下一阶段落地计划展开讨论；收集各业务线使用诉求与试点意向，明确平台共建方向与资源诉求。

> 实操准备：请学员提前准备 1 个 Figma 链接（或 1 张页面 / 组件截图）+ 公司 Git 账号；模块 2 现场即可产出并推送第一个组件。
>
> 时间提示：大纲按 105 分钟（约 1.75 小时）设计。如需严格控制在 90 分钟内，建议将模块 3 与模块 4 合并为「实操答疑与平台计划讨论（约 15 分钟）」。
