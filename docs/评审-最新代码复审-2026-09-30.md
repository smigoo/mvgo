## 2 P0 级

### P0-1 取值域扩到 `{grid, null}`，但写产物层仍是二值逻辑

**取值域变化**（`section-tree.js:2120`，Bug4-①）：

```js
function deriveChildLayout(node, layoutFacts = null) {
  const fact = (id && layoutFacts && layoutFacts[id]) || null
  if (!fact) return null
  if (fact.display === 'grid') return 'grid'
  if (fact.flexDirection === 'row') return 'horizontal'
  if (fact.flexDirection === 'column') return 'vertical'
  return null
}
```

改动前恒为 `{horizontal, vertical}`，**永不为 `grid`、永不为 `null`**；改动后 `section.layout ∈ {horizontal, vertical, grid, null}`。

**消费面四类归档**（`backend-node/src`，排除 `*.spec.ts`）：

| 类 | 点位 | `grid` 时 | `null` 时 | 判定 |
|---|---|---|---|---|
| A 严格相等 | `inline-row-assembler.js:45-46`、`section-content-guard.js:104`、`adversarial-checker.js:2024`、`section-tree.js:1008` | 不命中 | 不命中 | 安全（漏报不误杀；真 inline-row 由 `layoutSource==='inline-row'` 兜住） |
| B 带默认 | `subcomponent-planner.js:1045`、`prompt-builder.js:1753`、`section-tree.js:1156`、`constraint-reinforcement.js:58`、`code-structure-validator.js:1715` | 原样透传 | **静默兜 `'vertical'`** | ⚠️ null 臆造回潮 |
| **C 二值收缩** | **`code-generator.js:637`**、`section-content-guard.js:776` | **`column`** | `column` | 🔴 **错误/退化** |
| D 显式 grid | `figma-section-heights.js:251-268`、`resource-mounter.js:2831`、`layout-facts-injector.js:175`、`prompt-builder.js:1721`、`constraint-reinforcement.js:61`、`code-structure-validator.js:1739`、`subcomponent-planner.js:1021` | 正确 | 部分兜 column | 正确（但见下方缺口） |
