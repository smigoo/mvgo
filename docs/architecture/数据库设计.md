# mvgo 数据库设计文档

> 版本：v1.0 ｜ 日期：2026-08-12

---

## 1. 概述

| 项 | 说明 |
|---|---|
| 数据库 | MongoDB（阿里云 RDS） |
| 数据库名 | `langgraph-server` |
| ORM（Java） | Spring Data MongoDB |
| ORM（Node） | Mongoose（@nestjs/mongoose） |
| 连接方式 | Java / Node 共用同一 MongoDB 实例与库 |
| 集合数量 | 15 个 |

> **安全要求**：敏感字段（API Key、Git PAT）使用 AES-256-GCM 加密落库，MongoDB 中不存在明文。

## 5. 安全设计

### 5.1 加密存储

| 集合 | 加密字段 | 加密方式 | 密钥来源 |
|------|---------|---------|---------|
| `user_ai_configs` | `configEnc` | AES-256-GCM | `FIELD_ENCRYPTION_KEY` 环境变量 |
| `ai_git_credentials` | `tokenEnc` | AES-256-GCM | `FIELD_ENCRYPTION_KEY` 环境变量 |

- 明文通过 Mongoose 虚拟字段（virtual）透明桥接，业务代码无需感知加密过程
- MongoDB 中**不存在明文**，即使数据库被攻破也无法获取密钥

### 5.2 密码策略

| 来源 | 哈希算法 | 标识前缀 |
|------|---------|---------|
| Node 注册 | bcrypt (salt=10) | 无前缀 |
| Java 注册/迁移 | PBKDF2 | `{java-pbkdf2}` |

### 5.3 脱敏

- `operation_logs` 的 `body` / `query` 字段在写入前脱敏（API Key、密码等不不落明文）
