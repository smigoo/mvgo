## 3. 治本判据（①-γ）

在 ①-β 之后、② 之前新增一路：

1. **前置证据**：`section.id` 精确命中 Figma 图元 **≥2 段**（强身份证据，非位置猜测）。
2. **剩余区域**：从 `collectSectionRegions` 结果中剔除「已被命中项消费」的区域——区域自身是命中项 / 区域是命中项的**祖先**（容器已认领）/ 区域是命中项的**后代**（已含在段内）。
3. **严格等量才采纳**：未命中段数 与 剩余区域数 **严格相等** 才配对，多一少一率 `fail-open` 放弃（不猜）；恰多 1 且首项为 header 类（名匹配 + 高度 ≤80px）时按既有 header 容错剥掉（header 走 base-panel header slot 不进 body sections，本模块既有约定）。
