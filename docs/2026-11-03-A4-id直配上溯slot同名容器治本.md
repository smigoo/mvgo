## 3. 修法（假设，真机验证为准）

`applyFigmaSectionRatios` ①-β id 直配采纳前，对每个命中节点做**同名 slot 容器上溯**：

1. 从命中节点沿 parentId 链上溯（上限 4 跳）；
2. 祖先名严格匹配 `slot-{section.name}`（trim 后全等，不做模糊/包含）⇒ 用祖先的 effectiveH 替换；
3. 找不到 ⇒ 保留原配对（fail-open 不猜）。

判据特征：
- **纯结构**：只认名字精确相等（`slot-` + 段名），不认 id 白名单/组件名特判；
- **同构单一来源**：上溯判据只在 `applyFigmaSectionRatios` 内一处实现；
- **stats 计数**：`slotAncestor` 命中数（0 也打——恒 0=未生效可辨）；
- **不与既有路径冲突**：①-β 优先级不变（figmaNodeId > ②-α 根下直配 > ①-β > ② 顺序），上溯只在 ①-β/① figmaNodeId 命中节点的**采纳值**上做替换，不改变配对选择本身。
- 顺带覆盖 ① figmaNodeId 直命中路径（同一替换点，单一函数）。
