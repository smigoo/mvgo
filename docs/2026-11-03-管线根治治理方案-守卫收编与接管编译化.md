## 1.5 权属矩阵：谁在主笔（用户问「视觉模型是否完全接管」的代码答案）

**结论：不是。现状 = LLM 主笔 + prompt 负向约束 + 守卫事后纠偏；只有刀53/54 接管的 11 种 kind 实现了完全接管。**

| 子系统 | 现状主笔 | 真值来源 | 纠偏/修补（补丁所在） |
|---|---|---|---|
| 段落骨架（sections 划分/顺序） | 🟡 vision+planner（E1 拍板：骨架=vision、精确尺寸=Figma） | Figma 树 + vision JSON | P0-2 结构顺序门禁、R8-1/R8-5 幻觉段收敛 |
| 布局（flex 方向/尺寸/间距） | ❌ **chunk LLM 主笔** | Figma bbox/A4 高度比例/nodeLayoutFacts | V8/V9 几何注入、刀16 间距、FLEX-001~005、刀28/30/50——**全部实锤布局事故在此区** |
| header 插槽 | ❌ LLM 渲染内容 | vision headerSlots（互斥裁决） | T1/T1'/C2/刀57 四代修补 |
| 图表（type/数据/容器） | ❌ **LLM 写 echarts option 代码**（chartSpec 只是 prompt 软约束，`vue3-prompt.js:15`） | vision chartSpec + `_extractChartDataFromFigma` | T2/T3/N1/N2/chart-type-guard/双刀——**最大补丁簇** |
| 图例 | 🟡 legendItems 真值已提取（N2 注入时携带）；legend kind 可接管 | vision+Figma | LLM 自由渲染时靠 N2 兜底 |
| 文本/数字 | ❌ LLM 自由文本抄写 | Figma TEXT 真值白名单 | TEXT-TRUTH/N1/刀54 事后对账 |
| **已接管 11 kind**（grid/header/statrow/table/list/text/icon/legend/kv/footer/regions，`folded-grid-section-takeover.js:3540`） | ✅ **确定性模板，跳过 chunk LLM** | Figma 真值直编译 | 仅 R6 出口对账——**此区守卫密度≈0，因为确定性产物不需要守卫** |

**两个铁证**：① `vue3-prompt.js` 内数十条「严禁」（严禁固定 min-height 兜底 :270、严禁假设同方向 :328、严禁卡片整体居中 :342、严禁 bg.value :380……）——**用负向约束清单防 LLM 犯错，本身就是权属错配的自供状**；② 守卫密度与接管覆盖率严格负相关：LLM 主笔区 30+ 守卫/3.4 万行，接管区几乎零守卫。所有实锤事故（布局全错类）都落在 LLM 主笔区。

**理论修正（对「视觉模型完全接管」的两点限定）**：
1. **接管主体不能是 vision 单独**——vision 自身不可靠（覆盖率门禁 60%、visual-trust conflict、`applyHallucinationDrop` 幻觉剔除、`_overrideVisionDimensionsWithFigma` 用 Figma bbox 覆写 vision 尺寸、`docs/2026-10-31-vision形态漂移治理方案.md` 在案）。vision 单独接管 = 把「LLM 过度发挥」换成「vision 幻觉」，照样打补丁。
2. 正确表述：**接管主体 = Figma 结构真值（骨）+ vision 语义（肉）+ 确定性求解器/编译器（手），LLM 降级为语义映射决策与 freeform 兜底**。结构、布局、插槽、图表、图例全部走「真值→spec→确定性编译」，LLM 不再产出布局 DOM。

G1~G4 即把 ❌ 区逐个变为 ✅ 区：chart（G1）→ 布局出处/G2 → 文本资源（G3）→ 全量收编（G4）。每收编一区，该区守卫群按 patchHitReport 数据退役。

> 🔄 **限定（CR12 / 复核意见 F4）**：上句「LLM 不再产出布局 DOM」是**终态**，其前置条件是 CR7「G1.5 生成前置化」，且须区分两条装配路径（真跳过 LLM / 生成后覆盖），不得据总纲 §2.1 P6 单路径描述推定已实现。
> 🔄 **退役判据限定（CR8 / 评审 B3）**：`hit=0` 对 FLEX-001~005、V6/V8/V9、W4 刀23 等跨段补丁结构性不可达；须先落「不可退役簇清单」+ N/M 定义，否则「净删 2.5 万行」不可复核。
