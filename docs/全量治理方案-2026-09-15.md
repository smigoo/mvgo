## 0. 方法论（删减法）

所有视觉问题的共同根因只有一句：

**视觉确定性事实没有在「生成时」由代码强制落盘，而是交给 LLM 自由生成 + 事后纠偏。**

后处理与 LLM 一样会注入错误（R4、刀 21 收窄误放行已实锤）。唯一治本：

1. 圈定 LLM 不该碰的事实（结构树 / bbox / 资源归属 / item 内部 DOM / display·flex·grid / fills）。
2. planner + assembler 生成时装配；LLM 只填业务文案、数据映射、交互。
3. 每接管一件事，删对应纠偏器。**门禁/规则总数必须下降。**

验证纪律：离线重放（不调 LLM）→ 真机 `reuseCache:true` → jest 基线逐字同名同数 → `node --check` 扫 `src/**/*.js` → build/dist → 独立 commit。

改后处理前先确认 Vision 链路：全新 / vision-cache / `_uiCache`（`reuseCache:true` 走③，cache 是加工后结构）。

### 2.1 机制

刀 21 第一版：「凡 `数字:数字` 在 Figma 树不存在 → 剔除」。全语料 162 份误伤审计后收窄为：

> 只有「**自身无任何节点身份**却引用不存在节点」才剔。

`selfClaimsNode` 把 `sec.id` 匹配 `/^\d+:\d+$/` 当成「声明了身份」。差样本多出的：

- `8439:8500` 设备类型网格区
- `8788:8439` 切换控制区

是 Vision 编造的 id 空间（Figma 树不存在）。**假 id 自己给自己开绿灯，整块放行。** planner 把本该在 `@antd/tab`（`89:37`）内层的 3 列网格拆成兄弟 `CardGrid` → slot-con 纵向堆 Switch / Tabs / Grid，「左窄 tab | 右网格」消失。TabsSection 自己又复制一份网格（`duplicateTextIssues`）。

次因（放大观感，非外层根因）：`@color-text-base=#fff`；`[自动修复]` stub 给 label/title 灌 `display:flex`。

### 2.2 治本（已完成 ✅）

**最终方案比原「改 selfClaimsNode」更精准**——原因：全语料审计发现「假 id 就删」会误删真图表（traffic 的 `3550:194`、env-monitor 的 `8100:8110` 图表区，这些也是编造 id 空间，但真值树有 `@echarts` 节点、内容是唯一来源）。

真正根因不在 `dropHallucinatedSections`，而在 `subcomponent-planner.js#collectSourceNodeIds`：

```
collectSourceNodeIds 只认 `数字:数字` 形态，把 Vision 编造的假 id（8439:8500/8788:8439/3550:194）
也塞进 sourceNodeIds → 编造 section 伪装成「有归属壳」→ 下游 anchor 的 isShell 判据恒 false、
dedupe 的「无归属壳判别力」失效：真 chart 壳不再锚定、假 grid 壳被拆成独立 CardGrid。
```

**落地（`section-tree.js#stripFabricatedSourceIds` + planner 接入）**：

- 新增纯函数 `stripFabricatedSourceIds(sections, figmaRoot)`：清掉 sourceNodeIds 里「Figma 格式但真值树不存在」的假 id，语义 id（`slot-xxx`）原样保留。
- `subcomponent-planner.js` 在 `anchorPhantomSections` **之前**调用它，让编造 section 回到「无归属壳」状态。
- 下游既有机制自动接管：`anchorPhantomSections` 锚定真 chart（补真实 `@echarts` 归属）；`dedupeByWholeRegionShell` 判别力剔除假 grid/tabs 壳。

**离线重放（三样本 + 全语料 546 份 analysis.json 审计）**：

| 样本 | 原始 section | 治本后 | 结论 |
|---|---|---|---|
| 228b63d5（差） | 5（含假 grid 8439:8500 + 假 tabs 8788:8439） | 3（header/switch/tabs） | ✅ 假壳全剔，无独立 CardGrid |

| traffic f3d39255 | 8（3 个假 id chart 3550:194/336/638） | 8 | ✅ 3 chart 被 anchor 锚定到 @echarts，一个不丢 |

全语料 11 类「编造 id」section：5 类真 chart（`8100:8110`/`7950:8000`/`8000:2000`/`3550:*`）被 anchor 救回，6 类重复臆造（`8000:8010` 统计行、`8776:8787`/`8788:8439` tab、`8439:8500` grid、`badge-indicator`）被正确剔除，真实内容都另有归属 section 承载，零误删。
