## 1. 问题与根因（一句话各一条）

- **问题**：写盘前 30+ 守卫 pass、命名口径 76 模块 / 44,727 行，持续打补丁仍止不住「LLM 过度发挥 → 结构布局错误」。
- **根因（唯一）**：**确定性工作被交给了概率模型**——布局几何、真值抄写、图表接线、资源接线全部可由 Figma/vision 真值确定性推导，却由 chunk LLM 自由文本产出，再由守卫事后修补。守卫只是症状管理，不是治疗。
- **已被代码验证的出路**：刀53/54 接管家族——命中的段**整文件由 Figma 真值确定性渲染，跳过 LLM chunk**（`microcode-engineer.js:209`），接管区守卫密度≈0。根治 = 把这条已被验证的路从小众路径推成主路径。

## 2. 目标态架构（三层，全部复用在仓模块，不新建平行层）

```
[真值层]  Figma 树（骨） + vision JSON（语义/肉）
            │  编译为结构化 designFacts（已有雏形）
            ▼  src/ai-engine/context/design-facts-compiler.js(202)
               + generation-context-assembler.js(403)
               + context-conflict-resolver.js(134)
               + generation-context-shadow.js(108)
[决策层]  接管评估（folded-grid-section-takeover，kind 登记制）
            │  命中 → 确定性编译产出（跳过 LLM）
            │  未命中 → freeform 逃生舱 → chunk LLM（保留现有门禁）
[编译层]  确定性模板 + 布局求解器 + 真值槽位填充（本方案要建设的主体）
            │
[LLM 残域] 仅语义映射决策 + freeform 形态；不再产出布局 DOM、真值文本、图表 option
```

**LLM 职责终态**：只做「这一段是什么」的语义映射与 freeform 兜底；「怎么排版/写什么字/画什么图」全部编译产出。

## 3. 北极星指标：确定性接管覆盖率

> 根治进度只用一个指标度量：**组件产物中由确定性编译产出的 DOM 节点/样式声明占比**。

- 当前基线：11 种 fg kind（`FG_TAKEOVER_CLASS_RX`，`folded-grid-section-takeover.js:91`）+ P6 模板装配——小众路径，具体占比待 S1 观测数据。
- 守卫退役不是独立目标，是覆盖率上升的**被动结果**：某区被接管后，该区守卫按「连续 N≥20 单 hit=0」降级为只报断言、再按 M≥10 单零命中删除。
- **不可退役簇（明示，避免自欺）**：FLEX-001~005、V6 dedup、V8/V9 注入、W4 刀23 等**跨段补丁**的 hit 由布局区决定——在布局编译化（S3）落地前其 hit 结构性不可能归零，**不进入退役名单**；它们的退役与 S3 完成绑定，不设中间判据。

### S3 布局编译化（C 档核心，根治主体）

- **做什么**：布局求解器——消费 `buildNodeLayoutFacts` + nodeLayoutFacts/itemFacts（K7），对未接管段直接**求解产出** flex/grid/尺寸/间距契约，注入确定性模板；LLM 不再产出布局声明。
- **为什么现在能做**：V8/V9 注入器已证明「真值足以判定每个容器缺什么方向/尺寸」——求解器与注入器消费同一份真值，只是把「补缺」换成「生成」。
- **随之变化**：V8/V9/FLEX 簇从「写改 pass」降级为「只报断言」（产物与真值对账，违例 WARN 进 review 循环，总纲 §4-3 口径）；事故二正反向剥离随 dirty-tag（属性出处）落地根治——**dirty-tag 是本阶段的机制之一，不是独立目标**（总纲 §6 已登记的待治理项，续接而非另立）。
- **前置依赖**：S2 完成 + 覆盖率数据显示布局簇为最大残域。
- **退出判据**：布局簇补丁（FLEX/V6/V8/W4/刀16/刀28/30/50）进入退役流程；`LAYOUT-FACTS-CONFLICT` 计数行归零后该断言转纯校验。

### S4 文本/数字槽位化 + 双端合一（C 档收尾）

- 文本/数字不再由 LLM 抄写：槽位编译期填充自 Figma TEXT 真值（扩展总纲 C4「S3 真值填槽」）；TEXT-TRUTH/N1/刀54 转断言；prompt 收窄该职责（CODE-008 同理降为断言）。
- mc/vue3 共享同一接管器与编译规则表（`matchFgTakeoverTargets` 双端唯一映射先例）；engineer 内联后处理区迁入共享层；**两条装配路径收敛为一条「真跳过 LLM」路径**（K4 路径①为准），生成后覆盖路径（`applyDeterministicIndexTemplate`）退役。
- 终态：总纲改写为「编译规则表 + 断言表」；freeform 逃生舱永久保留（不阻塞新设计稿）；守卫层 44,727 行 → 编译规则 + 断言目标 6~8 千行（量级口径见 §4 表注，取数命令写死可复核）。
