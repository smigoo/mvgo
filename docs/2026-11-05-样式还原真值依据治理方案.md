### 2.2 根因不是「有推断」，是「静默」+「来源标签造假」

- 推断在真值缺失时**不可消除**：Figma 没有 `box-sizing` / `lineHeight` / `whiteSpace` 的对应字段。
- 真正致 bug 的是**静默写死**：值进了产物，任务日志、checkpoint、report 里都看不到它从哪来。
- 更上游的诱因是**假来源标签**：`prompt-builder.js:2835` 下发给 LLM 的段落标题为「主题变量真值（从 Figma 元素样式程序化合成，必须精确使用）」、正文称「变量名和色值由设计稿实测得出」，但 `:2821-2826` 中 `@text-color` 深色时恒为 `rgba(255,255,255,0.9)`、`@border` 恒为常量、`@border-radius-base` 缺数据兜 `8px`、`@gap` 兜 `12px`。**兜底常量被冒充成实测真值喂给 LLM**，LLM 遂把兜底值当设计事实照抄 → 直接催生 L5 臆造。
- 同类措辞共三处：`:2787`、`:2793`、`:2835`。其中 `:2787` 已诚实区分「实测 / 事实未覆盖按默认主题补齐」，`:2835` 最严重；P3 需逐处复核，不能只改一行。

### 2.5 🔴 真机离线复核（B 档实施后）：§2.4 的推论被证伪

**方式**：不重投、不部署。用刚 `npm run build` 的 `dist/` 模块，喂 `8deeb6c4/.mc-gen/resource-dom-mapping.json`（9 条真实条目），对 `role=bg` 的 4 条调 `inferBackgroundStyle`，再跑 `pickStyleTruthAudit` + `formatRejectSummaryLine`：

REJECT-SUMMARY styleTruth:evaluated=9,scaleMode=0,geometry=4,noBg=5,unknown=0

## 3. Phase 3 治本方案（假设，待真机验证）

### 3.1 命题（支 1 裁决）

> 所有写进产物的样式值必须能追溯到一条明确来源；**无来源的必须显式标注并留痕，不得静默写死**。不一律 BLOCK。

### 3.2 作用域白名单（支 2 裁决）

- 白名单 = `visual.json#**/styles` 的键集合 ∪ `figma.json` 真值字段集合，**程序化生成**，不手写常量清单（满足「禁止硬编码」）。
- 平台契约豁免必须是**显式可枚举白名单**（`box-sizing`、`overflow`、`whiteSpace`、`lineHeight` 常量、`@fontSize` 基准、主题槽位 `var()` 透传），并标 `source:'platform-contract'`。
- 🔴 **禁止**留「凡无真值即视为契约」的兜底 —— 那会变成新的静默逃逸口。

### 3.3 来源分级

| 级 | 来源 | 示例 | 处置 |
|---|---|---|---|
| L0 | Figma 字段直读 | `fills`、`scaleMode`、`absoluteBoundingBox`、`fontSize`、`cornerRadius`、`itemSpacing` | 免标，天然有据 |
| L1 | `visual.json` 真值 | `styles.fontSize/color/backgroundColor` | 与 Figma 冲突时**以 Figma 为准**（呼应 #532 交叉验证） |
| L2 | 确定性派生 | 几何比率、`coverageRatio`、`sortByVisualOrder`、flex 比例 | 公式 + 命名常量 + `inferredBy` |
| L3 | 平台契约（白名单） | `box-sizing`、`overflow`、`@fontSize` | `source:'platform-contract'` |
| L4 | 兜底 / 默认 | `#333333`、`0px 0px`、`8px`、`12px` | 强制 `inferredBy:'fallback'` + 恒打计数 |
| L5 | LLM 臆造 | `#3a4a5c` | 无据且无标记 → **唯一必须拒写** |

### 3.4 处置档位（支 3 裁决）

| 级 | 动作 | 落点 |
|---|---|---|
| L0~L3 | 正常写入，L2/L3 带来源标记 | 既有写入口 |
| L4 | 允许写入，**强制**记进 `reject-summary` 新增来源统计子集 `{attr, value, source:'fallback', file}`，恒打计数（0 也打，延续 `pickTakeoverAudit` `:82-95` 纪律） | `reject-summary.js` 扩展位 + 两处 graph 聚合点 |
| L5 | **在写入出口拒写**（置 `null` / 不输出）+ 计数，**任务仍 completed** | `renderFoldedGridLeafVue` 构造 `FG_LIST_ITEMS` 处（`:3079-3098`），即 `8deeb6c4` 刀 A 既定形态 |

排除「全观测不拒写」（`#3a4a5c` 会继续落进产物，与命题冲突）；排除「L5 硬 BLOCK」（`less-compile-gate.js:1494-1497` 已证任务必失败）。

### 3.5 存量三分类（支 4 裁决，零数值改动）

| 类 | 对象 | 动作 |
|---|---|---|
| P1 已补真值 | `sizeFromScaleMode`（仅位图节点，见 §2.5） | 只**接线** `inferredBy → reject-summary 来源统计子集` + 计数，不改任何值。⚠️ 「5/5 覆盖」已证伪，但「只接线不改值」的结论不变 |

- ❌ 不新增修补型守卫、不新增第二套判据、不新增 `contractAudit` 语义外的字段。

- ❌ 不改产物、不按任务 id / 组件名特判、不加 try-catch 掩盖。
- ❌ 不重投、不部署、不 `git push`。
