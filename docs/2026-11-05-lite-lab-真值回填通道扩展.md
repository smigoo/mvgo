## 修法（全部派生自真值/既有结构事实，零硬编码）

### 1. 采集最小集（A1' 只为资源服务，A2 容器色不采）
- service 反哺块扩前缀：icon-/**bg-**/**g-** 全部造真值条目。
- 新增 `findNodeById(root, id)`（truth-matcher 导出），反哺条目补 `absoluteBoundingBox` 的 width/height（假设：bbox 即渲染尺寸，真机验证为准）。

### 2. 命名↔结构双锚定消费（bg-* → CSS background 替换）
- 文件名解析：`bg-tab-active-7891.png` → 前缀 `bg-` + 核心段 `tab-active`（剥尾部 `-{数字id}`）。
- 产物侧：扫 .vue `<style>` 规则，选择器类名归一（`--`→`-`）后**包含**核心段。
- 双闸门：①全产物命中类数 = 1（歧义放弃）；②规则体已有 `background` 键（只换已有键，不插新键）。
- 替换：`background: <原色值> url('<深度>/resources/images/<fileName>') center / 100% 100% no-repeat`——保留原色做兜底，background 不参与布局（不破坏布局红线）。
- g- 前缀 v1 只反哺采集+计数，不消费（无稳定判据，留给 AI 兜底立项）。

### 3. img 全路径尺寸还原
- 空变量路径：绑定变量时向对应 `<img :src="变量">` 标签注入 `style="width:Xpx;height:Ypx"`（直接映射，确定性）。
- svg v-for / 空字段 / dataUri 路径：共享标签（v-for 驱动），仅当**全部**绑定资产尺寸一致（unanimous）才注入；否则保守放弃。
- 锚定路径已有 sizeStyle，不变。

### 4. 计数行（0 也打）
AssetMountStats 扩：`bgAnchored` / `bgSkipped`（含原因分类：无类命中/歧义/无 background 键）/ `sizeRestored`；service 日志行 + report.stats 透传。
