## 2 证据链（全部确定性，逐条可复现）

### 2.1 P-01c 剥壳 → 宿主 `::before`（真凶定位）

- 源码：`src/ai-engine/utils/post-process.js`
  - `:2091 convertShellToPseudoElement(code, shell)`「绝对定位装饰壳 → 宿主 `::before`（铁律收口）」
  - `:2174` 插入文本模板：`'\n\n  .' + firstCls + '::before {\n    content: \'\';\n    ' + topDecls + '\n  }'` ← **2 空格缩进**
  - `:2193 out = out.replace(shell.full, '')` ← 模板删壳
- 产物比对（缩进与格式**逐字符吻合**）：
  - `package/components/StatsSection.vue` 模板第 **14 / 25 / 36 行变成空白行**（原为 `<div class="c-vehicle-monitor-stat-card-bg"></div>`）
  - `resources/styles/common.less:188-191` 与 SFC `:106` 各出现一条 2 空格缩进的 `.c-vehicle-monitor-stat-card::before { content:''; … }`
- LLM 原始 chunk（`.mc-gen/cache/code-chunks/4-package_components_StatsSection.vue:128-133`）：
  ```less
  .c-vehicle-monitor-stat-card-bg { position: absolute; inset: 0; background: @color-primary-bg; pointer-events: none; }
  ```
  ⇒ **几何本来就是 `inset:0` 铺满宿主** ⇒ P-01c 的转换 **几何等价，不是失真**。
- ⚠️ 因此本缺陷的**唯一病根是颜色取值**（见 2.2），不是几何。

### 2.2 根作用域主题取值（跨主题语义污染）

`resources/styles/themes/theme-vars.less` 中 `@color-primary-bg` 的三个取值：

| 位置 | 值 | 语义 |
|---|---|---|
| `.theme-light()` 内 `:27` | `rgba(25, 144, 255, 0.10)` | 透明淡蓝 ✅ |
| `.theme-dark()` 内 `:79` | `#414141` | 不透明深灰 |
| **顶层兜底** `:136` / `:155` | **`#ffffff`** | **不透明纯白** 🔴 |

`resources/styles/index.less:4-11`：
```less
.common();
.theme-light();   // 注释声明「必须是第一个被调用的主题（mixin 注入 = 先调用者胜出）」
.theme-dark();
```
⇒ 契约意图：**根作用域应取 light 值 `rgba(25,144,255,0.10)`**。

**实测编译产物**（`resources/styles/index.css`）：

| 作用域 | `.stat-card` 本体 | `::before` 蒙层 |
|---|---|---|
| 根（无主题类祖先） | `rgba(102,128,160,0.34)` 半透明灰蓝 | **`#ffffff`** ⇐ 不透明，完全盖住本体 |
| `.light` | `rgba(255,255,255,0.72)` | `rgba(25,144,255,0.1)` ✅ |
| `.dark` | `rgba(26,35,50,0.72)` | `#414141` |

⇒ **index.less 的注释契约未被满足**：根作用域取到的是顶层**普通赋值** `#ffffff`，而非 `.theme-light()` 的 mixin 注入值。
（`style-tokens.js:1475-1484` 注释已自行澄清语义：mixin 注入 = **先调用者胜出**；普通重复赋值 = **后者胜出**；两者同作用域混用时实测**普通赋值压过 mixin 注入**。）

### 2.3 主题兜底补全块非幂等（重复两份）

`resources/styles/themes/theme-vars.less` 共 163 行，其中 `// 写盘门禁自动补全缺失变量` 出现 **3 次**：`:120`（`style-tokens.js:1461` 生成模板自带）、`:130`、`:149`（`file-writer.js:2088` append 两次）。同批变量被重复补了**两遍**。

`src/ai-engine/roles/microcode/file-writer.js`：
- `:2027-2030` `declaredSet` 的来源是 `tvContentNow = files[tvPath] + pendingThemeVars`，**`files[tvPath]` 缺失时回退空串、不读磁盘**（对比 `:2085-2087` 的 `existing` 有 `readFileSync` 兜底）⇒ 第二次调用时 declaredSet 漏掉磁盘已声明项 ⇒ 重复补。
- `:2088` `const tvContent = \`${existing}\n// 写盘门禁自动补全缺失变量\n${pendingThemeVars}\`` ⇒ **纯 append，无去重/清空**。
- `pendingThemeVars` 定义 `:977`，两处 `+=` 累积（`:1306`、`:2060`），append 后未重置。

### 2.4 非法色值（色值位塞尺寸）

`theme-vars.less:139` / `:158` 兜底出 `@color-over-height-number: 0px;`（同时 SFC `<style>` 段顶部也被补了一份）。
