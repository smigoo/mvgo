## 2. 真机根因

任务：`mc-max-1793660003799-39a9de97`，终态 failed，重试预算 1 次耗尽。

真实日志两次均为：

```text
package/components/ContentSection.vue: 模板引用了 script 中未声明的变量/组件（record、column）
```

离线消费该任务 `.checkpoint/analysis.json + figma.json + resource-dom-mapping.json`，确定性接管得到 `ContentSection kind=table`，模板含：

```vue
<template #headerCell="{ column }">…</template>
<template #bodyCell="{ column, record }">…</template>
```

`record/column` 是 Ant Design Vue 插槽参数，合法且不需要 script 顶层声明。`sfc-semantics.js#extractTemplateRefs` 当前只把 `v-for` 变量放进 `loopVars`，所以同一确定性产物两次均被误拒。

同一真实渲染结果还含：

```js
const hStyle0 = { box-sizing: border-box, text-align: center, vertical-align: middle };
```

这些是非法 JavaScript 对象键；A 修完后必须先让 B 的语法判据暴露，再修 B，禁止用跳过错误掩盖。

## 3. 治本契约

### A：模板插槽作用域（判据假设，待真实回放）

- 在唯一模板引用抽取器 `extractTemplateRefs` 中识别 `v-slot`、`v-slot:name`、`#name` 的属性绑定。
- 支持单个标识符、简单对象解构和别名、简单数组解构；绑定名并入现有 `loopVars` 返回集合，保持对外 API 不变。
- 复杂嵌套/默认值不盲目豁免，避免把属性名或表达式引用误判成局部绑定。
- 仅豁免插槽声明的本地变量；插槽体内其它未声明变量继续阳性命中。

### B：table JS 样式对象

- 在 fg-table 渲染源头把三个连字符键统一写成带引号的 JS 键，样式值保持原样。
- 用真实 SFC 脚本语法解析验证，不只 grep 字符串；其它 kind 与其它样式对象不改。
