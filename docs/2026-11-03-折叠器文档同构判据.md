## 修法（Phase 3）：折叠证据三层 OR，几何降级为兜底

```
折叠放行 = L1 文档同构声明 ∨ L3 几何签名（现有，逐字不动）
```

- **L1（新增）**：`docAnalysis.uiElements`（S8 文档子管线产物，schema :205-225）中**同 api + 同控件类型**的元素名组，与段树兄弟段名归一化匹配（剥「数量/值/标签/统计/卡片」数据后缀，危化品车数量↔危化品车）；命中 ≥2 构成证据组；未命中兄弟段与核心成员几何弱相似（同行±4px+等高±8px）可并入
- **否决门**：核心成员间不满足弱相似 ⇒ 放弃（声明噪声防御）；词表为语言学后缀规则（非业务词特判），命名无关原则不破
- **落点**：`collapseRepeatedSiblingSections`（:478）在几何分组为空时走 L1 fallback——几何路径行为逐字不变，零回归
- **透传链**：graph :4355 / planner-node :41 加 `docAnalysis` → plan opts → :2951 `collapseSectionsDeep(…, { docGroups })`
- **产物标记**：折叠段挂 `_foldEvidence:'doc'`；planner 折叠日志区新增计数行

## 判据（可辩驳）

1. 真机计数行：`📄 文档同构折叠生效 (groups=N, members=M, names=[…])`（改者判据）
