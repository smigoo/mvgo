## 1. 根因 A（主因，两个会话都中）：`parentTexts` 只写在 IMAGE-fill 分支，而本设计稿资产全走「反哺」

本设计稿（`2:8417` / `2:7879`）**没有任何 IMAGE fill**（节点缓存统计 `imageFills=0`）。
资产 PNG 是 `downloadAssets` 按**命名启发式**（`icon-<id>.png` / `bg-<id>.png`）导出的，随后在
`lite-lab.service.ts` 的反哺段按「文件名后缀 → nodeId 反查」造真值条目。

上一轮把 `parentTexts` 加在 `collectFigmaTruth` 的 `if (imageFill)` 分支里 ⇒ **一次都没执行**。
反哺条目只有 `siblingTexts: []` + `nearbyTexts`（同一「父层/祖父层直接 TEXT」口径），对整图卡底图
同样为空。

证据：真值 18 条 `parentTexts` 全为 `None`；`assetNoSiblingTexts=15`；`bgAiStructCand=0`。

**修法**：抽 `collectAncestorTexts(root, nodeId, {hops=3, cap=12})` 作为唯一取词来源
（模块级节点索引缓存，避免重复建树），`collectFigmaTruth` 的 IMAGE 分支与**反哺段共用**。

## 2. 根因 B（会话 1 两个 AI 候选）：聚合 label 的双卡同名局部词把 LCA 拉到无 bg 键的容器

产物结构：

```
.stat-cards                       ← 无 background 键
  .stat-card .stat-card--primary  ← background: linear-gradient(...)
    .stat-row      总数: 56302
    .stat-row--sub 隧道设备 异常数: 5
  .stat-card .stat-card--secondary ← background: rgba(255,255,255,.75)
    .stat-row      总数: 1280      ← 与左卡同名
    .stat-row--sub 南北接线设备 异常数: 3
```

宽松匹配下「总数:56302」与模板叶子「总 数:」双向包含成立 ⇒ **左右两卡各命中一次** ⇒ LCA 泛化到
`.stat-cards`（无 bg 键）⇒ 祖先回溯只往**上**找，而正确挂载点是 LCA 的**后代** ⇒ `skipNoBgKey=2`。

**修法（两层，均为收紧而非放宽）**：

1. **数字严格档 + 两轮匹配**：词含数字段而叶子不含（或数字段不相容）时不算命中；严格档零命中才
   回退宽松档（精确优先、召回不降）。
2. **长数字词定簇**：结构 label 分词后「总数:」会独立成词（无数字）⇒ 第一层仍挡不住；label 里
   ≥4 位长数字是区分同名卡最强特征，命中集里凡能匹配长数字词的节点作为种子重定 LCA，弱命中丢弃。

实测三层效果（同一产物、同一 label）：

| label 形态 | 修前 | 修后 |
|---|---|---|
| AI 形态「总数:56302 隧道设备 异常数:5」 | skipNoBgKey | → `.stat-card--primary` |
| 结构形态「隧道设备 总数: 56302 异常数:」 | skipNoBgKey | → `.stat-card--primary` |
| 「总数:1280 异常数: 南北接线 设备」 | skipNoBgKey | → `.stat-card--secondary` |

## 3. 根因 C（观测）：`bg-ai-response.json` 落错目录

原实现用 `dirname(dirname(shotPath))` 推 cache 目录 ⇒ 落到 `<output>/resources/.cache`，与会话
`.cache`（`figma-truth.json` 所在）分离，排障时找不到 AI 到底给了什么。
**修法**：`runBgAiFallback` 显式接会话 `cacheDir`。
