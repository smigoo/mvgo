### 3.2 质量缺陷根治

| 缺陷 | 治理前 | 治理后 |
|------|--------|--------|
| 图例被误识别为独立 section | vision 输出图例作为 section → 规划层生成独立子组件 | vision 侧引导 + 规划层 `mergeLegendSections` 合并到相邻图表 |
| 伪造 series 阈值线 | LLM 用假 series 模拟 → 图表逻辑错误 | prompt 禁止 + 后处理 `rewriteFakeThresholdSeries` 改写为 markLine |
| 重试轮结构漂移 | 隔离坏文件 → 重试 → LLM 重排结构 → 更坏 | `extractComponentSkeleton` 注入骨架约束 LLM 只重生成失败分块 |
| 臆造 theme 变量 | 6 个 `@color-tab-*` 靠启发色兜底 | vision themeVars 真值三级 fallback 注入，消除臆造空间 |
| section 尺寸比例缺失 | tabs 等附属区 height:100% 挤占主图表 | prompt 强制附属区固定高度 + 主内容区 flex:1 min-height:0 |

| S3 大分块拆分 | 多图表 section 按图表二次拆分并行，单分块体积减半 |

### 3.4 资源变量幽灵引用根治（批次四）

| 缺陷 | 治理前 | 治理后 |
|------|--------|--------|
