## 4. 三合一判据设计

单一纯函数（扩展现有 `roles/microcode/subcomponent-coverage.js`，不新建第二份），输入 `{ subPlan, files }`，输出：

```
{
  expected,            // isForced ? minFiles : 0
  generated,           // package/components/*.vue 一级文件数
  missingSubcomponents: [ { subId, responsibility, missingAnchors[] } ],
  anchoredGroups,      // 至少 1 条锚点落进独立 .vue 的组数
  unanchoredGroups,    // textTruths/elementNames 全空的组数
  orphanFiles,         // 存在但未被任何 .vue import 的文件
  skippedReason        // 未就绪时 'no-plan'，否则 null
}
```

### 4.1 数量
`generated >= expected`。口径不变（布局容器不占槽，二级目录不计）。

### 4.2 逐组内容锚点
对每个 `internalSubcomponents[i]`：
- 锚点 = `textTruths ∪ elementNames`（planner 已产出，`subcomponent-planner.js:1090-1105/1126-1139`）。
- 命中条件：**至少 1 条锚点出现在某个 `package/components/*.vue`（非 index、非父 section 文件）**，且不同组不得全部落进同一文件。
- **空锚点组退化**：锚点集为空（纯图形/图表组）时不计入 `anchoredGroups`，计 `unanchoredGroups++`，该组只由「数量 + 引用完整性」兜底；日志必须打 `unanchored=N`，避免「没锚点」与「锚点全命中」同形。

### 4.3 引用完整性（全产物引用图）
- `findDeadSubComponentImports`（`code-structure-validator.js:547`）**只分析单个文件 content**，不能直接用于本判据；新建「全产物引用图」遍历：收集所有 `.vue` 的 `import ... from './X.vue'` / `defineAsyncComponent(() => import(...))` / `require(...)`，得到被引用集合。
- **import 解析复用同一实现**（禁止复制第二套正则）；遍历范围仅是新增逻辑。
- 孤儿文件定义：`package/components/*.vue` 中**未被任何产物文件引用**者。合法豁免：`index.vue` 本身、`declare` 相关、`variant` 变体目录（如有，需实现时 listed，禁止按名字猜）。

### 4.4 判据可辩驳性
- 单一来源：不复制 `vue3-engineer` 逻辑，共用 `minFiles` 语义；锚点只认 `textTruths/elementNames` 结构，不认文件名。
- 阳性对照：402679ed 数字 `expected=5 generated=3 missing=2`，group3 的 6 条卡片文本（摄像机/风速风向仪/超高检测器/烟道机器人/激光雷达/CO₂传感器）全部不在任何独立 `.vue`。
- 阴性对照：`isForced=false` ⇒ `expected=0` 不产 issue；数量达标 ⇒ `missing=0`；bootstrap 写盘 ⇒ `skipped:no-plan`。
- 边界：`.less` / `ts` / 二级目录不计一级槽位；入参缺失不抛错。

## 6. 口径分层（与既有裁决的关系）

既有裁决（`section-coverage-guard.js:312-314,342-344`；总纲 `:160`；11-05 文档 `:149`）：「文件不存在 ⇒ 不重试、不 BLOCK，只 `artifactIncomplete`」。本方案不推翻它，而是**拆两类**：

| 类别 | 形态 | 处置 | 依据 |
|---|---|---|---|
| **A 类（沿用旧裁决）** | 引用悬空 / 被 P1-4 隔离降级 / 收尾断言命中（C8②、D1） | 不重试、不 BLOCK；只 WARN + `artifactIncomplete=true` | 无 `guidance` 可用，重试只会重放同一份源码 |
| **B 类（本方案新增）** | planner 强制清单缺件（`internalSubcomponents` 未落独立 `.vue`） | 允许带 `guidance` 走 L0-B 重试；耗尽仍软失败 + `artifactIncomplete=true` | `guidance` 非空 ⇒ `isL0BRetry` 重新生成分块（`:1767-1785`），前提已变 |

> 口径漂移说明：旧裁决的依据「重试只会重放同一份源码」在 2026-08-31 D 步修复（`:7804`）后对**带 guidance 的重试轮**已不成立，但文档未同步。本次把边界写清，避免第三套口径。
