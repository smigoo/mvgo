## §2 根因（三层）

- **RC1（上游，遗留已知）**：vision `layout.sections` 无 children、`charts[]` 无 id 无父级（前序立案「vision chart 段 id 失锚」），planner 只能产出 3 个扁平 content section，5 个 @echarts 节点不在任何 section 的 sourceNodeIds 里。
- **RC2（中游，本次主刀）**：`chart-section.js#injectChartSectionIfMissing` 把 5 个「未覆盖」@echarts 节点合成的 chart section **追加到根末尾**（模块自己 2026-09-26 注释已记录病灶「追加到根，丢掉位置」）：① 视觉序撕碎（Content×3 在前 Chart×5 在后）；② 刀16b 兄弟间距在错误相邻关系上补偿出 421px/91px/62px；③ 与宿主组件自绘图表双渲染。F1 根容器高度契约（b338e4a）让容器真实高度生效后，margin+flex 叠加 → 段溢出重叠 → 「图表消失/section 缺失/样式失效」。
- **RC3（放大器）**：`generation-context-assembler.js#normalizeComponentPlan` 白名单重建把 plan 级与 section 级 `internalSubcomponents` 剥掉（droppedKeys 观测 8）→ `state.generationInput`（生产输入，phase2 graph:1631 采用 shadow generationInput）里宿主永久丢失名下图表归属。

## §3 修法（F1+F2）

### F1 几何宿主归属 + 根级 Y 归并（chart-section.js）

`injectChartSectionIfMissing` 尾部三分支：

1. **同 id 图表语义宿主 → 就地替换**（2026-09-26 既有路径，不动）；
2. **几何宿主**（新）：@echarts 节点 bbox 中心点落在叶子 section Figma 盒内（取最小面积=最内层；`type==='chart'` 不当宿主；盒缺失跳过）→ 挂为宿主 `internalSubcomponents`（R1 同款 shape：chart-component/chartData/chartConfig/legendClick/dataZoom）+ plan 级记账（parentSectionId），**不做根级注入** → 顺序/比例/间距天然正确、单渲染；
3. **无宿主**（真兜底）：根级**按视觉 Y 归并插入**（稳定排序，无几何事实落尾部=等价旧 append）。

计数行：`[chart-section] 图表兜底注入裁决 {chartSections, replacedInTree, hostedByGeometry, rootMergedByY, rootOrder}`（0 必现）。reason 串同步三分支计数。`minFiles = leafCount + internalSubcomponents.length`（对齐 planner R1 口径）。

### F2 internalSubcomponents 透传（generation-context-assembler.js）

- `BODY_PASSTHROUGH_KEYS` 放行 `internalSubcomponents`；
- 新增 `normalizeInternalSubs` 最小契约归一化（type/id/name/responsibility/reason/parentSectionId/parentSectionTitle/props/emits/sourceNodeIds/chartType/elementNames/textTruths），plan 级与 section 级同契约透传；
- droppedKeys 对其余内容型字段的 R8-7 观测不破。
