## §2 Phase 3 治本方案（判据标注：假设，以真机验证为准）

### 刀56 · 两行 tabs 双保险（裁决：双保险）

1. **prompt 铁律**：prompt-builder 生成「叶子 Section 级子组件清单 / 内部子组件详细说明」处，追加硬约束：
   > 「叶子 section 文件的模板根**只允许**引用已拆分的内部子组件标签（`<XxxArea/>`）；已拆给子组件的内容**禁止**在本文件再内联渲染一份（含 v-for 复刻、类名复刻、静态结构复刻）。内部子组件存在时，本文件除子组件标签外不得出现承载其内容的 DOM。」
2. **写盘前校验**（挂既有校验器，落点候选 `code-structure-validator.js`，实施时定）：
   - 输入：叶子 .vue 模板 AST/文本 + 其内部子组件 .vue 的 class 名集合（来自 planner `internalSubcomponents` 关系 + 子组件文件扫描）。
   - 判据（假设）：叶子模板中出现「仅由内部子组件声明的特征类名」的 DOM 节点（且非子组件标签本身）⇒ 命中重复渲染。
   - 处置：WARN + 计数行（先观测后收紧，避免首版误报拒收）。
   - 计数行：`leafInlineDuplicate=hit/checked`（0 也打），登记总纲。
3. **阴性保证**：无内部子组件的叶子（多数段）⇒ class 集合空 ⇒ 校验零开销零命中，产物不变。
