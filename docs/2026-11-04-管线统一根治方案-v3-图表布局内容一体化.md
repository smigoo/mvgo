## 1. 治理原则（不可违反）

1. **单一事实源**
   - 结构、几何、图表、内容、样式各只有一个权威事实源。
   - 任何 pass 只能消费事实源，不允许私自复制一套判据。
2. **真值编译优先**
   - 可由 Figma/vision 真值确定性推导的，一律由编译层产出。
   - LLM 只负责语义映射和 freeform 兜底，不再主笔布局、图表 option、数值、标题控件。
3. **禁止新增修补型守卫**
   - 新增守卫默认拒绝。
   - 只允许新增：事实源、编译器、断言、观测计数。
4. **Fail-open / freeform 保留**
   - 无法确定性归属时回退 freeform，不允许为了“看起来正确”硬猜。
   - 结构或图表宿主无法解析时，只报观测计数，不得整单 fail-closed。
5. **可回滚**
   - 每阶段独立 commit。
   - 每阶段必须有独立 worktree 两态回归基线。
6. **禁止打补丁**
   - 不允许按任务、组件、类名、间距数值加特判。
   - 不允许在错误拓扑上继续修补间距、样式或图表高度。
   - 不允许绕过事实源直接改产物。

### 阶段 C0：结构事实层（前置，必做）

**目标**：把 `section-structure-contract` 从 index 装配扩展为全链路结构事实源。

**范围**
1. planner / assembler 保留 `header.controls`。
2. 结构契约持久化到规划产物，供 chart、布局、内容、样式共用。
3. 消费 `figmaNodeId/sectionId/id` 三重互补证据。
4. chart 宿主归属证据进入契约，不猜。
5. 任何 section 注入、替换、去重后统一做 Figma 几何顺序校验。

**禁止**
- 不新增独立“chart 归属守卫”。
- 不按组件名、类名、任务 ID 猜宿主。
- 不把 freeform 改 fail-closed。

**验收**
- `chartHostResolved / chartHostUnresolved` 计数落 component-meta。
- Forecast 头部控件在 prompt 与产物中一致。
- 两任务重放后 section 顺序与 Figma 几何一致。
- mc / vue3 / lite 三路径分别验收。

**实施状态**
- 2026-11-04：已完成 C0.1 `header` 结构事实透传（planner/assembler），mc / vue3 / lite 定向测试 44/44 通过。

**目标**：图表从 LLM 主笔改为确定性编译。

4. T03、轴翻转、chart 高度守卫降级为断言，不再写改。
5. 无法接管的 chart 段走 freeform，不做硬拆。

**验收**
- chart 接管命中率非零。
- RUNTIME-010 中 chart 相关错误归零。
- 视觉评分不低于当前基线。
- 不再出现 T03 误注入 min-height。
