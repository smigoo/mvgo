## 3 修复优先级

   - 治：banner 空白、空胶囊、假「开关设置」面板
3. **L2 table 卡片形态否决**（列成员子树含 `@echarts`/背景层 ⇒ 拒绝接管）
   - 治：车型分布长期错（上一轮 A 项）

### P1

4. **L1 行分组**（同 y 带兄弟段归入 horizontal row）
   - 治：左侧导航跑到上方、图标与标题被拆成上下
5. **L3 禁硬编码 margin/width + 高度预算校验**（margin 总和 + 段高 ≈ 容器高 ±5%）
6. **L2 契约缺类型 fail-closed**（`type` 为空时禁止 table/statrow 这类破坏性接管）
