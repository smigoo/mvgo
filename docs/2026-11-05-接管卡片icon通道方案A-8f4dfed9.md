## §2 治本修法

### 2.1 真值侧（`cardTruth` 扩维）

新增 `subtreeIconTruth(node, resourceMapping, firstTextX)`：

- 候选 = 卡子树（depth≤2，与 `subtreeBackground.walk` 同深度）内 `isIcon(n)` 且 `bboxOf(n)` 存在的非文本节点；
- **选择判据（可辩驳，零猜测）**：取 `x` 最小者（最左 icon）；平票取面积最大；仍平票取 id 字典序（确定性）；
- 输出 `icon = { varName, file, dx, w, h, gap }`：
  - `dx = round(icon.x − card.x)`（icon 左缘真值）
  - `w/h = icon bbox 真值`
  - `gap = round(首文本x − (icon.x + icon.w))`（icon→首文本真值间距）
- **pad/gap 改写**（仅 icon 命中时）：`pad → dx`、`gap → gap`（原 pad = dx+w+gap 的 icon 区被真实 img 替代）；无 icon ⇒ pad/gap **逐字不变**。

### 2.2 渲染侧（grid 渲染器 :3806-3865）

- 独立 `iconVars` 池（与 `bgVars` 同构：唯一 import 变量 + 去重下标），产物尾部 `const FG_GRID_ICONS = [...]`；
- 卡片模板 runs 之前插入：
  `<img v-if="it.icon != null" :src="FG_GRID_ICONS[it.icon]" :style="{ width: it.iw + 'px', height: it.ih + 'px', flex: '0 0 auto' }" />`
- items 载荷追加 `icon/iw/ih`（仅 icon 命中项）。

### 2.3 阴性保证（结构性）

卡内无 mapping 命中 icon ⇒ `iconVars` 空 ⇒ 无 `FG_GRID_ICONS`、无新 import、items 无 icon 字段、`<img>` 恒 v-if 假 ⇒ **产物逐字不变**（RC3 同款结构保证）。
