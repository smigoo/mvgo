## 4. 治本方案（候选）

### A（推荐）：产生处——「最终模板无挂载 ⇒ 图表 script 禁令/跳过」
判据（纯结构、与门禁同源思想）：**最终 templateContent 中不存在任何 `ref="X"` 挂载 div**（`<div[^>]*\bref="`）。模板无挂载 ⇒ script 里任何 `echarts.init` 必然孤儿（script 不能反向修改 template）⇒：
- scriptSplit 拆段路径：把 `_forcedSplit` 判据扩为 `isForced || templateHasNoChartMount(templateContent)`，命中即跳过 charts 段；
- 单 chunk 路径：script 段 prompt 注入硬禁令「父模板无图表挂载点（图表已由子组件承载），禁止在 script 写 echarts.init/option/图表数据」。
- fail-open：模板有挂载 → 零行为变化。
- 边界与门禁 :341 同口径（`this.$refs`/getElementById 提取不到 ref 名 → 跳过判据不适用，维持现状）。

### B：出口回环——do-not-invent BLOCK 进 L0B 修复反馈
BLOCK 时构造针对性反馈（删父级孤儿图表代码）进 L0B autofix，而非终态 throw。LLM 修复非确定性，但覆盖 A 漏网的一切残留（含 state 段死变量）。

### C：写盘出口确定性剥离孤儿 echarts 死代码
正则剥 JS（已知反面教材），风险高，不推荐。
