## 2. Phase H 是什么（病灶 / 判据 / 实现）

### 病灶（根因，代码证据）
`detectUnknownText`（`src/ai-engine/utils/text-truth-guard.js:245`）的候选**只**由 `CHINESE_RUN_RE = /[\u4e00-\u9fa5]{2,}/g`（`:19`）生成 ⇒ **纯 ASCII token（`zh1`/`sta`）属 docstring 明写的设计豁免，天然不入检查**。
→ 实锤：`e7da39ca` 组件 `43:4791` 行值「启用」被替换成 `zh1`，**零拦截**。

### 治本 = 并列第二条口径（不是复用主口径）
- 新增 `ASCII_TOKEN_RE = /[A-Za-z_$][A-Za-z0-9_$]*/g`（**首字符禁数字** ⇒ 纯数字串如 `3740` 不入候选）+ `ASCII_TOKEN_MIN_LEN = 3` + 五类框架词白名单（生命周期&组合式 API / 事件名 / 指令 / JS 关键字内建 / 常见标签属性 CSS 单位）。
- 🔴 **判定 = token 边界小写全等**（`truthTokens.has(tok)`）。**刻意不复用 `isCoveredByTruth`**（去空白 + 子串双向覆盖），否则 `sta ⊂ status` / `able ⊂ disabled` 误报爆炸，且 `dev ⊂ DEV2201` 反向漏报。
- 真值口径同构：`collectFigmaAsciiTokens` 与 `collectFigmaTextTruth` **同走裸节点递归 `TEXT.characters`**（不取 `.document` 包装），防两口径视野漂移。
- `businessTextRules.rewrite` 目标词的 ASCII token 并入真值（与中文口径同语义）；真值空 ⇒ fail-open 返回 `[]`。
- **零漂移分层**：结果独立进 `textTruthAsciiStats`，**不进 `unknown` 数组** ⇒ 既有动态分级链（`code-structure-validator.js:2496-2507`「标题级或 >2 处即 BLOCK」）**逐字未动**。先观测后收敛。

### 留痕三态（`hits:0` 也必打，照 `font-size-guard.js#formatFontGuardLog` 范式）
| 态 | 含义 |
|---|---|
| `enabled:false` | 该链路未传 `figmaNodeData`，**口径根本没跑** |
| `enabled:true truthTokens:0` | 跑了但真值侧无 ASCII token（**fail-open**） |
| `enabled:true hits:0` 且 `truthTokens>0` | **真正干净** |

### 双形态接线
`mc-component-graph-phase2.js:4905`（tag `max`）／ `mc-component-graph-vue3.js:2850`（tag `vue3`），均在 `CodeStructureValidator.validate(...)` 调用**之后**打日志行。
