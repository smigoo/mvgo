# 横向容器尺寸口径：T-GROW（T-TOPO 的必要配套）

- 日期：2026-11-05
- 触发：T-TOPO（横向容器重建）落地后自查发现——**尺寸口径仍只有高度一维**，会让 `46 : 367` 渲染成 `~52 : 48`
- 结论：补「宽度事实 + 方向感知归一」，否则 T-TOPO 的收益被比例错误吃掉
- 用户裁决：走 **方案 A（宽度比例 grow）**

## 1. 根因证据（Phase 2）

### 1.1 方向与轴不匹配

| 项 | 事实 |
|---|---|
| `applyFigmaHeightGrow` | 逐层算 `grow = 高度 / 本层平均高度`，**无方向分支**；`:2417` 递归进容器 `children` 时沿用高度口径 |
| CSS 语义 | `flex-direction: row` 时 `flex-grow` 分配**宽度**；`column` 时才分配高度 |
| 真机数值 | `89:39` = 46×317、`2:8437` = 367×295 |
| 现状产出 | `grow = 317/306 = 1.036` / `295/306 = 0.964` ⇒ 渲染 ≈ **52% : 48%** |
| 设计真值 | 宽度比 `46 : 367` ⇒ **11% : 89%** |

⇒ T-TOPO 把结构改对了，尺寸口径没跟上，比例反而更离谱（比原来的 column 全宽更容易被误判为「好像对了」）。

### 1.2 为什么不能直接用 `figmaSectionBox` 取宽

`figmaSectionBox` 只读 `section.sourceNodeIds`；vision 主路径的 section **没有这个字段**（`debug-ai-response.txt` 的 3 个 section keys 里无 `sourceNodeIds`）⇒ 返回 `null` ⇒ 宽度取不到。

## 2. 修法（Phase 3）

### 2.1 新增纯函数 `unionSectionBox(section, index)`（`section-tree.js`）

- **并集**：section 自身引用（`id / figmaNode / figmaNodeId / figmaAnchorId / sourceNodeIds`）+ 递归子树（`children / body.children / body.items`）里所有形如 `\d+:\d+` 的 Figma id；
- 返回 `{x, y, width, height}`（无任何可解析节点 ⇒ `null`）；
- **与 `figmaSectionBox` 严格分工**：并集盒用于「量尺寸」，min-y 单节点盒继续用于「排序」，两者不得互相替代。

### 2.2 `applyFigmaHeightGrow` 改方向感知（保留函数名，避免大范围改名噪声）

```
apply(list, direction)
  axis = direction === 'row' ? 'width' : 'height'
  direction === 'grid' ⇒ 不参与（列宽由 grid-template-columns 决定，改 grow 无意义）
  每项取 axis 事实：
    width  → styles.figmaWidthPx || unionSectionBox().width
    height → styles.figmaHeightPx  || figmaSectionBox().height   ← 保持既有语义不动（C1 单独立项）
  grow = axisValue / 本层平均
  同时把 width 事实落库：direction==='row' 时写 styles.figmaWidthPx（供下游 code-generator 读取）
  递归：apply(s.children, dirOf(s))，dirOf = /grid/ ⇒ grid，/horizontal|row/ ⇒ row，否则 column
顶层 apply(nodes, 'column')
```

### 2.3 硬约束

1. **不新起方向判据**：复用 `subcomponent-planner.js:1817` 同一正则 `/horizontal|grid|row/i`（与 `extractLayoutMetadata` 的三态口径对齐）；
2. **不改 `figmaSectionBox`**：它的 min-y 语义服务于排序，改它会牵动 `sortSectionsByFigmaY`；
3. **只改 row 轴**：column 与既有行为完全一致（零回归面）；
4. **计数行**：`flexGrow 已按 Figma 实测…重新归一` 日志补 `axis` 字段（row/column）与 `skipped`（grid / 无量测）。
