## 五、迭代功能：HTML 原型读取（用户指定放迭代，3~5 周）

**定位**：在 Figma URL 之外增加「HTML 原型」输入源，遵循 `docs/html-prototype-standards.html` 标准（单文件 + 内联依赖 + 无外部资源）。这是减少报错的另一根杠杆——HTML 是确定性输入，无 vision 误读、无 Figma 限流、图表 type/颜色/字号可直接从源码提取真值。

### 分期

**M1 解析器（管线侧）**
- 新建 `html-prototype-parser.js`：DOM 解析 → 结构树（容器层级 / 内联样式 → 颜色·字号·尺寸 / class 归属段）
- 内联 `<script>` 提取 echarts option → 图表 type/series 确定性真值（替代 vision 推断，直接消灭 DO-NOT-INVENT-CHART 类死因）
- 输出映射为与 vision JSON 同构的 section-tree 格式，**下游（microcode-engineer → file-writer → 门禁 → 自愈链）零改动复用**

**M2 管线打通（mock→真机）**
- lite/mc-max 入口支持 `prototypeHtml` 输入（与 figmaUrl 二选一）
- 投递验证：同一视觉目标走 Figma 路径 vs HTML 路径，对比失败率与还原度
- 判据：HTML 路径 3 连投 completed，RUNTIME/VISUAL 类死因显著低于 Figma 路径

**M3 前端入口（components.vue）**
- 投递面板增加「HTML 原型」tab：文件上传 / 粘贴源码两种方式
- 解析预览：结构树 + 提取到的图表清单回显，确认后再投递
- 判据：端到端截图验收

### 风险与边界
- 复杂 CSS（grid/伪元素/外部字体）解析降级策略：解析不了的样式回退 LLM 生成，标注置信度
- HTML 原型同样要过既有门禁（不豁免），但预期命中率高很多
- 四象限同步：入口先挂 mc-max + lite，vue3 视验证效果排期
