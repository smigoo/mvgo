## 病灶链（0f0468b7 真机日志）

1. vision 段 48:5888（底部汇总「共6个节点」+接入设备统计）锚点选在 TEXT 叶子自身；
2. `visual-parser` LCA 修复失败（`anchor-not-ancestor`：内容 48:5889 不是 48:5888 后代）；
3. planner 记 self-reference（body.children[0].childId = 自身）；
4. 覆盖闭包退化：`cov[48:5888] = {48:5888}`（size=1，仅自身锚点）；
5. 一段判据 `isSubset({自身}, strictCov(565:3))` 通过（该 TEXT id 在 565:3 闭包内）⇒
   判「full 覆盖」⇒ **整段移除** ⇒ 底部汇总 + 接入设备统计（48:5889 子树）消失。

**本质**：`size:1 ⊆ size:N` 的子集判定在「锚点退化成自身单节点」时无信息量——
闭包不含段内容（48:5889 不在闭包也不在吸收者闭包），「完全覆盖」是假象。

## 修法（figma-coverage-dedupe.js 一段判据）

`isSubset` 通过后、`droppedBy.set` 前加豁免（`reason:'full'` 路径独有）：

```
cov[i].size === 1
  && cov[i].has(String(sections[i].id))          // 闭包恰为自身锚点
  && Array.isArray(sections[i]?.body?.children)  // 且声明了内容结构
  && sections[i].body.children.length > 0
⇒ continue（保留，宁多勿漏）
```

- 语义：锚点退化（正常段锚容器时闭包≥容器子树，size=1 说明修复失败）⇒
  覆盖证据不可信 ⇒ fail-open 保留；
- 豁免的段正常走后续管线（LLM 生成底部汇总组件）——内容恢复由生成侧承接。
