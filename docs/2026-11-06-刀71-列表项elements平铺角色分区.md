# 刀71 — 列表项 elements 平铺角色分区（canonicalListItem 角色轨补全）

日期：2026-11-06 ｜ 实锤：mc-max-1793908403023-8f7451ae（合作厂商弹窗）「华为技术8台」连排

## 病灶

vision 对 fg-list 行内「名称+数值」给出 **content.elements 平铺角色数组**：

```json
{ "content": { "elements": [
  { "type": "label", "text": "华为技术", ... },
  { "type": "value", "text": "8台",   ... }
]}}
```

`canonicalListItem`（section-semantics.js 单一实现）旧回退链只认两形态：
- `el.parts`（value 容器 + number/unit 子节点）
- `it.children` 角色子树（刀28a：content / stat-value role）

**「平铺 + type:label/value 角色标记」形态缺失** ⇒ `type:"value"` 的「8台」被
`normListText` 当普通文本 push 进 texts ⇒ 产物 `texts=[华为技术,8台] stats=[]`：
- 名称与台数连排 span（margin-left:auto 右值区 `v-if="it.stats.length"` 恒假失效）；
- detectListLeaf 双轨比分**两轨同染**（figma 拍平轨与 vision 富卡轨都走本函数）
  ⇒ `stats>0 权重 1000` 双方恒 0 ⇒ 平局维持拍平轨，vision 富卡轨永远救不回来。

## 修复（section-semantics.js#canonicalListItem）

elements 消费循环在 parts 判据之后新增分支：

```js
if (ROLE_VALUE_SET.has(roleOf(el))) {   // role||type 归一读法，词表 vision-facts 单一来源
  const vn = normListText(el);
  if (vn) contentStats.push({ v: vn.t, l: '', vc: vn.c, vfs: vn.fs, vfw: vn.fw, lc: null, lfs: null });
  continue;
}
```

- value ⇒ 单文本 stat（value 单独成值、label 空）——走 contentStats 通道，
  显式 `it.stats` 在场时自然让位（`statEntries.length===0 && contentStats.length>0`
  才并入），杜绝双份；
- parts 优先级不变（带 parts 的 value 容器仍走 parts 轨，与 769789af 口径一致）；
- 无角色标记（type:text 等）维持拍平轨零漂移。
