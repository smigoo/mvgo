## 3. Phase 3 五刀设计

### 3.1 刀 1 · C1 全资源守恒断言（只报不改）

- **续接点**：`reject-summary.js:19-20` 明留扩展位 + 上一轮第三源 `pickStyleTruthAudit` 同构；判据复用 `resource-facts.js:129 buildResourceFacts`。

- **修法**：新增第四源 `pickResourceConservationAudit(resourceDomMapping, files)`；`files` 取 `result.generatedFiles`（phase2 为 path→content 对象，`:1864`），vue3 无该对象时标 `filesUnavailable=1` 并如实打 0 分档。统计 `expected / excluded(missing|skipMount) / mountable / declaredVar / imported / unmounted / noVarName / notImported / orphanImports`。

### 3.2 刀 2 · C3 console 噪声单一事实源（去误判）

- **根因**：`screenshot-renderer.js:689-691` 函数内 `ignoredConsoleErrorPatterns`（1 条）与 `:53-57` 模块级 `RUNTIME_BENIGN_CONSOLE_PATTERNS`（3 条）**两套事实源**；`:177-181 isFatalConsoleError` 经 `LOCAL_RUNTIME_URL_PATTERNS:79` 把 `node_modules/.vite/deps/chunk-*.js?v=` 当本地运行时代码 ⇒ 一条 antd Table `rowKey` deprecation warning 被升级为 `RUNTIME-010-FATAL`（`server.log:34709`）。
- **修法**：① 合一为模块级 `CONSOLE_NOISE_PATTERNS`，渲染期过滤与分类期 benign 共用；② 新增**结构性**噪声判据：文本为第三方库 warning（`^Warning:` + `deprecated`）且来源 URL 属 `/node_modules/` 或 `/.vite/deps/`；③ `isFatalConsoleError` 对第三方依赖 URL 不计 fatal。纯函数 export 供 spec 直接验证。
- **阳性对照**：`40c7c1a7` 真机文本 + `chunk-DA6NNJFW.js?v=` → benign / 非 fatal；**阴性对照**：组件自身 `index.vue` 的 `TypeError` 仍 fatal、`Permissions policy` 既有豁免不回退。
- **明确不做**：不改 `v3Mode` 分层、不改 `classifyRuntimeGate` 的 BLOCK 名单、不放宽 `DETERMINISTIC_MISSING_PATTERNS`。

### 3.3 刀 3 · VISUAL-002 证据有效性留痕（只报不改）

### 3.4 刀 4 · 装饰层祖先承载漏判（唯一写盘行为改动）

- **根因确证**：`723d52c3/package/components/ContentAction.vue` 里资源在 `<img :src="icon2" class="…-action-icon">`，而 `common.less:26` 的 `border/background/border-radius` 写在父 `<div class="…-action-btn">`。`collectResourceCarrierClasses:505-528` 只收资源标签自身 class；`_clsMatches:353-357` 只认全等 / `-` 后缀 ⇒ `…-action-icon` 与 `…-action-btn` 永不匹配 ⇒ `stripBakedDecorationFromFiles` 恒不命中。
- **修法**：模板信号增加**结构判据**——用配平标签栈扫描模板，把「**直接子元素是资源位图 `<img>`**、且其间无文本」的**直接父容器** class 并入 carriers。只认 DOM 结构（标签语义 / 父子 / 兄弟数 / 文本），**不认类名前缀、不认组件名**，符合门禁「文本命名无关」。多兄弟父容器不入 carriers。
- 🔴 **判据收紧（定向回归实锤，非事后放宽）**：首版按「子树含资源」判定，把既有 `baked-decoration-strip.spec.ts` 的 `tab-item`（唯一子元素是带 `:style` 背景图的 div）误判承载，误剥了 spec 要求保留的 `border-radius`（2 例转红）。收紧为「直接子元素必须是 `<img>` 位图宿主」后既有 17 例全绿。带 `:style` 背景的 div 属 CSS 背景承载，由既有 ① 模板信号自己收，不触发父容器推定。
- **判据可辩驳**：阳性 = `723d52c3` 真实片段 → border 被剥；阴性 = 多子元素父容器 / 无资源宿主父容器 / `:style` 背景 div 父容器 / 属性含 `>` 不截断 → 零改动；改者用标签栈、验者比对产物 CSS 声明集合，不同实现。
