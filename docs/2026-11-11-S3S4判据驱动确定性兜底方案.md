## 方案设计

### S3：E3-v4 背景归属确定性补挂（RESOURCE phase）

**触发**（写盘前 pass，`pipeline.register`，`phase: FIX_PHASE.RESOURCE`，`applyTo: VUE`）：
输入 `ctx.resourceDomMapping` + `ctx.figmaNodeData`（S1 已并入 pipeline.context，同源复用）。

**判据**（确定性，复用 acceptance E3-v4 同口径但**独立实现**——改验分离）：
对 mapping 中 `previewAnalysisRole==='bg' && downloadStatus==='success'` 的资源 r：
- 找产物中 `data-section-id="r.ownerSectionId"` 的开标签；
- **不存在** ⇒ 在该资源 import 所在文件（`varSourceFile` 同源逻辑）的 template 里、资源变量已消费的最深公共祖先容器**内部**，注入：
  ```html
  <div data-section-id="{ownerSectionId}" style="width:{W}px;height:{H}px;background-image:url('{varName}');background-size:100% 100%;background-repeat:no-repeat;"></div>
  ```
  （W/H 取 figmaBox 四舍五入；varName 取该文件既有 import 变量，缺失则连 import 一并注入）
- **存在但未消费该 bg** ⇒ 在该开标签补 `:style` background 绑定（保留既有 style，幂等合并）；
- 已挂到祖先 ⇒ 从祖先移除该 bg 声明（挪到归属容器），避免双挂/拉伸。

**幂等**：容器已有 `background-image` 含该资源名 ⇒ 跳过。
**计数行（恒打）**：`🛡️ S3 bg 归属补挂·已评估 {scanned, missingContainer, mounted, moved, skipped}`。

### S4：G1-v2 tab 交互确定性注入（POLISH phase）

**触发**：真值 tab 段（`identifyNodeRole==='business' && name 含 tab`，与 G1-v2 同源识别）的承载文件无 `@click`。

**动作**（对承载文件 template 的 tab 段容器）：
- 容器开标签补 `@click="handleMcTabSwitch"`；
- 每个 tab 子项补 `:class` active 绑定 + `data-mc-tab-key`；
- script 追加标准三件套：
  ```js
  const activeMcTab = ref('{首个 tab 文本}')
  function handleMcTabSwitch(e) { /* 按 data-mc-tab-key 切换 activeMcTab */ }
  ```
（命名带 `Mc` 前缀防与 LLM 已写的 tabs/activeTab 冲突；若 script 已有任意 tab 状态变量 ⇒ 只补容器 @click 接线到既有函数。）

**幂等**：容器已有 @click ⇒ 跳过。
**计数行**：`🛡️ S4 tab 交互注入·已评估 {scanned, injected, skippedHasClick}`。
