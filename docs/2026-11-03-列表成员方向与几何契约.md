## 1. 查重结论

- 既有 `layout-direction-guard#resolveTruthLayout` 是 `horizontal-* / vertical-* / grid-*` 的通用归一判据；本刀复用并下沉为无环纯函数，不另写第二份字符串解析。
- 既有 `vfor-list-direction-guard` 已区分「wrapper=成员之间」与「item=成员内部」，但折叠段只读 `sec.layout || sec.body.layout`，在二者同时存在且冲突时仍由 `sec.layout` 独占，不能表达本样本。
- 既有 `grid-list-layout-contract` 负责多行等距网格；本样本是单行、异宽、负间距列表，不改用网格契约，也不放宽其判据。
- `folded-grid-section-takeover#detectListLeaf` 已有纵向卡高、间距与背景链接管；本刀续接同一返回契约，不新建第二种列表接管器。
- git 历史显示 T3/LAYOUT-001 已多次修复证据源与 display 语义；本次不是再改阈值，而是补齐「容器方向 ≠ 成员方向」的字段消费和冲突仲裁。

## 2. 真实根因与证据

真实样本：`mc-1793641875986-001c5615-c-vehicle-monitor-dc888541(文档纠偏)`。

### 2.1 声明同时存在，但渲染端丢弃成员方向

`.checkpoint/analysis.json#subComponentPlan.effectiveSections[0]`：

```text
id=136:122
layout=vertical
body.layout=horizontal-3-columns

```

`folded-grid-section-takeover.js`：

- 几何被 `geoReady` 的「全部卡同宽同高」统一绑定，导致异宽横向卡连宽度和横向间距也无法下发。

### 2.2 Figma 证明本样本是横向、异宽、负间距

| 成员 | x | y | width | height |
|---|---:|---:|---:|---:|
| 136:129 | 37 | 984 | 140.4815 | 74.1953 |
| 136:128 | 166 | 984 | 120 | 74.1953 |
| 136:127 | 274 | 984 | 141.0000 | 74.1953 |

因此：成员方向为 row；逐项宽度约 `[140,120,141]`；相邻 x 间隙约 `[-11,-12]`。负值是真实叠压，不得 clamp 成 0。

### 2.3 不能简单让 body.layout 永远覆盖 sec.layout

对 214 份真实 `analysis.json` 审计：434 个折叠/重复段中，`layout=vertical` 且 `body.layout=horizontal*` 的冲突样本共 3 个。

- 本样本与另一文档再生成样本：三卡语义为横向。
- `mc-max-1793594915493-37cc8b31`：六卡 Figma 盒 y 递增，明确是纵向；若盲取 body.horizontal，会把既有纵向列表改坏。

结论：字段冲突必须由 Figma 成员盒仲裁，不能设置固定的字段覆盖优先级。

## 3. 治本契约

新增无环纯函数契约，供接管器、LAYOUT-001 与 T3 共用：

```text
sectionDirection = resolveTruthLayout(sec.layout).direction
bodyDirection    = resolveTruthLayout(sec.body?.layout).direction
geometryDirection = 成员盒可证明的唯一主轴（row/column/null）

二者一致或仅一个发言 → 消费该声明
二者冲突且几何明确   → 消费 geometryDirection
二者冲突且几何不明   → 保留旧 sectionDirection（fail-open，不扩大行为变化）
```

几何只接受可辩驳形态：

- 所有成员同 y、x 有变化 → row；
- 所有成员同 x、y 有变化 → column；
- 两轴都变化（网格/乱排）或盒缺失 → null，不猜。

`detectListLeaf` 返回新增：

```js
{
  direction: 'row' | 'column',
  directionSource: 'declared' | 'geometry-conflict' | 'legacy-section-conflict' | 'default',
  cardWidths: number[] | null,
  // 既有 cardH/gaps 保留；row 时 gaps 改由 x 轴产生
}
```

渲染：

- row：根 `flex-direction:row;overflow-x:auto`，逐项 `width=cardWidths[i]`，相邻项写 `marginLeft=gaps[i-1]`；
- column：保持既有 `column/overflow-y:auto/marginTop` 行为；
- `cardH` 在横向只要求高度一致，不再被异宽阻断；宽度逐项表达，不虚构统一 `cardW`；
- 背景相关 `itemBg`、逐项 `bg` 与既有 `geoReady` 区块不改。

## 7. 刀55 修订：几何可证即真值（`bc473fa`，2026-11-03）

### 7.2 修订内容（续接 §2.3 原则，非新口径）

§2.3 已立原则：「字段冲突必须由 Figma 成员盒仲裁，不能设置固定的字段覆盖优先级」。本修订把该原则延伸到单声明/缺省情形：

```text
原第 2 条：仅一个发言 → 消费该声明
修订后  ：仅一个发言且几何可证且与声明相悖 → 消费 geometryDirection
          （directionSource='geometry-overrides-declared' | 'geometry-overrides-default'）
          其余形态逐字不变（一致/缺盒/两轴变/双声明冲突仲裁全不动）
```

依据：`inferListGeometryDirection` 极保守（任一缺盒/两轴都变/无变化 ⇒ null），非 null 即视觉真值；vision 段级 `layout` 语义是「标题/内容堆叠轴」而非「重复成员轴」（136:122 标题在上 ⇒ vertical，与三卡横排不矛盾），声明在该情形下本就不是成员轴的权威发言。`37cc8b31` 反例不受影响：其盒为纵向 ⇒ 几何判 column ⇒ 与声明一致，仍走 `declared`。
