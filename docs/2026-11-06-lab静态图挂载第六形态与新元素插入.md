## 1. 背景/根因（证据链见 2026-11-06 memory log）

- 5 资产 `siblingTexts` 全空（icon 与标题不同父）⇒ 全部转入 svg 兜底路径。
- 产物无 `<svg>` 占位，兜底链四形态（data-URI / iconClass / `icon:''` 字段 / 空变量）全不命中：
  - 顶部 2 大 icon：产物形态是 `const statIcons = { partner: '', device: '' }` **空值对象属性** + `<img :src="statIcons.partner" alt="合作厂商">` —— 链上无此形态。
  - 3 分组 icon：产物零引用，标题旁是 CSS 圆点假图标 `<span class="…group-icon"></span>`（规则 0.6 禁止 CSS 拼图形，LLM 违反）；plan 层标 `needs-new-element`「当前计划不主张」⇒ 无人落地。

## 2. 修法（全部落 `src/lite-lab/`，lab 独立，不动 `src/lite` 正式管线）

### 刀1 第六形态：`fillEmptyObjectProps`（truth-matcher.ts）

- **产物形态**：`const objVar = { prop: '', … }`（flat 对象，含嵌套 `{` 保守跳过）且模板存在 `:src="objVar.prop"` —— 「被 :src 引用」即 icon 角色结构证明。`icon:` 属性名让位给字段通道（`fillEmptyIconFields` 先跑、坐标同源，禁双改）。
- **锚定**：第一轮 img `alt` ↔ 资产 `nearbyTexts/siblingTexts` 语义锚（唯一命中才绑）；第二轮剩余属性 ↔ 剩余资产**数量相等才 zip**（声明序 ↔ 资产序，沿用既有「禁止瞎猜」纪律）。
- **编辑**：属性级 `prop: ''` → `prop: labAsset_x`（svgEdits 绝对偏移，统一重放），模板零改动；尺寸还原走 `injectImgSize`（正则限定 `:src="objVar\.prop"`）。
- 语义匹配判据抽成模块级 `assetSemMatch`（三通道共用，判据单一来源；`fillEmptyIconFields` / `replaceEmptyIconVars` 原地内联版同步替换，行为等价）。
- `replaceEmptyIconVars#bind` 补 `_consumed=true`（与字段通道一致），防对象属性通道复用已绑资产。

### 刀2 新元素插入：`insertNewElementAssets`（mountBySvgPlaceholder 兜底链末位）

- **准入**：资产有 fileName、非 `bg-`、未被任何通道消费（`_consumed`）。
- **锚定**：`nearbyTexts ∪ siblingTexts`（归一化 ≥2 字）在模板叶子**唯一精确命中**（0=无锚、>1=歧义，均保守放弃并计数）。
- **插入**：锚点开标签前插 `<img class="lab-asset-img" :src="labAsset_x" style="width:Wpx;height:Hpx" />`。
- 🔴 **防双图标**：锚点前 ≤240px 窗口（常量 `NEW_EL_LOOKBACK`）内若紧邻**空元素**（自闭合 `<x/>` 或 `<x …></x>`，结构性判据不认名字；`img` 除外）⇒ **替换**该空元素（正是 CSS 圆点假图标位）；无空元素才纯插入。
- 复用主循环同款 `consumed` 叶子防抢占纪律；import 注入同链。

### 计数器（真机日志 + 报告，可辩驳）

`emptyObjPropsReplaced` / `newElementInserted` / `newElSkipNoAnchor` / `newElSkipAmbiguous`，进 `truthBackfill:` console.log 与 `LabReportSummary.stats`。`svgSkipped` 聚合条件扩为「四通道全 0 才计入 sorted.length」（历史语义不变，部分挂载欠计为已知口径，不在本轮改）。

### 不做项

- 不动 `src/lite/lite.service.ts`（规则 0.6 已存在，是遵循率问题；lab 独立边界）。
- 不动 `backfill-plan` 的 inline-image `needs-new-element` 判定：plan 是 CSS 真值执行源，模板元素插入属挂载层管辖，无双重写盘；覆盖度由 mount 计数器与 planGaps 对读（gaps>0 且 newElementInserted>0 ⇒ 已兜住）。
