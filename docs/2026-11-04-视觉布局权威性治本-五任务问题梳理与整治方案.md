## §2 系统性根因：为什么「视觉布局正确却被替代」

布局传递链与断点（全部有真机证据）：

```
vision layout.sections（顺序/角色/几何 ✅ 正确）
  → planner effectiveSections（段序保持 ✅；header 滤除/段重解释 🟡）
    → 层① 确定性模板（段序 ✅）
      ├─ 尺寸  ✗ A4 sectionHeights → flex grow（相对比例）
      ├─ 间距  ✗ 刀16b → 绝对 px margin（错误 prev 盒时补偿出 305/421px）
      ├─ 内部布局 ✗ LLM freeform（vision 内部几何不进契约）或刀53 接管（texts 断供）
      └─ 兜底  ✗ N2/图表根级注入（位置无宿主约束、空数据）
```

**三个断点（治本对象）**：

1. **画布契约缺失（最深层）**：根容器 `width/height:100%` 流式，Figma 设计尺寸（420×186 等）从未锁进产物。预览容器 ≠ 设计尺寸时，**一切 flex 相对比例必然按错误画布重排**——这就是「布局被替代」的物理机制。视觉模型给的布局是绝对几何，产物却只用相对比例表达，尺寸权威从未落地。
2. **尺寸/间距双口径混排**：flex grow（相对）与 margin px（绝对）在同一列混用，只在恰好等于设计高度的容器里自洽；A4 比例（相对化）与刀16b 补偿（绝对化）互不同源。
3. **内容布局无权威**：vision 的段内几何不进契约——LLM freeform 随意发挥，或刀53/接管器抢走生成权但真值断供（texts:[]），或 R1 拆子组件只给 prompt 不给文件。
