📝 关键命名规则解析

根容器命名

❌ 错误：Frame 123 / Group 456
✅ 正确：cp-流量监测 / cp-traffic-monitor

影响：根容器命名决定组件整体标识，无意义命名导致代码可读性差

② 背景图命名

❌ 错误：Rectangle 45 / Background
✅ 正确：bg / bg-header / bg-card

管线行为：根节点 bg 跳过下载（透明底要求），嵌套 bg 挂载到父容器

③ 图标命名

❌ 错误：Vector 78 / Component 9
✅ 正确：icon / icon-filter / icon-arrow-right

管线行为：命名级整体 icon 整体导出 1 张图，不钻内部 VECTOR 碎片

④ 图表区域标记

❌ 错误：无标记 → 每个柱子被导出为独立 png
✅ 正确：@echarts/bar / @echarts/line / @echarts/pie

管线行为：标记 @echarts 的节点整棵子树跳过资源导出（运行时渲染）

⑤ 按钮/Tab 命名

❌ 错误：Button 1 / Tab 2
✅ 正确：btn-submit / btn-cancel / tab-active

影响：语义化命名保留到生成代码，提升可读性与可维护性

⑥ Auto Layout 属性

❌ 错误：无 Auto Layout → layoutMode=null
✅ 正确：layoutMode=HORIZONTAL/VERTICAL + padding≥8px + itemSpacing≥8px

影响：布局完全错乱 vs 精确还原间距与对齐
