## 使用流程

1. **打开配置面板** → 模型 Tab 顶部显示「模型方案」下拉
2. **切换方案** → 选择已有方案，表单自动填充
3. **另存为新方案** → 点击 💾 按钮，输入名称
4. **覆盖保存** → 点击 💿 按钮，更新当前方案
5. **重命名** → 点击 ✏️ 按钮，输入新名称
6. **删除** → 点击 🗑️ 按钮（default 不可删除）

## 技术亮点

- **向后兼容**：旧配置自动迁移为 default 方案
- **防御性编程**：default 方案不可删除、不可重命名
- **实时日志**：测试页面提供完整操作反馈
- **类型安全**：TypeScript 接口完整定义
