# Tab UI 骨架注入制造游离根 · 修复方案（①段锚宿主错配实为游离根第四次复发）

> 2026-11-10 · 状态：**已实施**（游离根 `759d0fc` + 双份 tabs 收口 `9d7726e`）
> 触发样本：重点车辆 `7cac7ab3`（4 组件批次）用户截图——左侧"江阴靖江长江隧道"被压一字一行竖排

## 1 查重结论

游离根家族已有三次治理：R11-A（file-writer 前归位）、R11-B（终写前归位，`348c7f5`）、S6（SFC 顶层块排除，`2af9b16`）。本轮为**第四次复发，制造者不同**：不是 LLM 直写，而是**写盘出口自愈注入的**——续接 R11 家族口径（归位而非判死），不另起炉灶。

## 2 根因（文件+行号+日志证据链）

| 环节 | 证据 |
|---|---|
| 真机写盘时 R11-B `relocated=false`（finalTruthFiles 干净） | F2 日志 `03:23:49.642` |
| 同一文件离线重跑归位器 `changed=true` 抓到 tabs 游离块 | 本轮离线重放取证 |
| 写盘出口 `Tab UI 骨架自愈` 触发 4 次 | 日志 `03:23:49.554/.608/.648` |
| 缺陷 A：`injectMissingTabUi` 用 lazy 正则 `/<template[^>]*>([\s\S]*?)<\/template>/` 提取模板体，被命名插槽 `<template #header-right>` 的 `</template>` **截断**（总纲 §已知反模式：lazy 匹配停在第一个内层闭合） | `code-healer.js:1216` 附近 |
| 缺陷 B：`injectTabBarIntoTemplate` 回退分支 `return bar + '\n' + tplBody` 把 tab 栏插到截断体最前 = **base-panel 开标签之前** | `code-healer.js:1401` |
| 结果：`content.replace(tpl[1], newBody)` 写回后 tab 栏成为 base-panel 外的游离根落盘 | 磁盘 7cac7ab3 index.vue 实证 |

时序拆台：R11-A/B 都在写盘前，`injectMissingTabUi` 在 writeFiles 出口（写盘后自愈链），制造后无人归位。

## 3 修法（治本 + 兜底，均复用单一事实源）

| # | 修法 | 位置 |
|---|---|---|
| A | 主模板体提取**配平化**：depth 计数 `<template` 开/`</template` 闭，取主模板块完整内容（消除 lazy 截断） | `injectMissingTabUi` |
| B | 注入位置约束：`-root` div → 次选 `<base-panel>` 开标签后（默认插槽首部）→ 仅当全文无 base-panel 才允许插模板最前 | `injectTabBarIntoTemplate` |
| C | **兜底**：Tab UI 注入后补跑 `relocateStrayTemplateRoots`（幂等、既有单一事实源），moved>0 打 WARN；放同一 try 内不新增哨兵 catch | `file-writer.js:1299` 同块 |

## 4 影响面

- `injectMissingTabUi` 唯一调用点 `file-writer.js:1299`；`relocateStrayTemplateRoots` 消费者 +1（pre-write-self-healing / microcode-engineer R11-B / file-writer 兜底），纯函数幂等零风险。
- `templateRendersTabs` 判据在配平后的完整体上运行——判定域从"截断体"变"完整体"，只可能**更准**（截断体可能漏判已渲染）。
- 哨兵计数不变（复用既有 catch）。

## 5 回归

1. 家族 spec：阳性（带命名插槽 + 无 tab 渲染 → 注入到 base-panel 内 + 无游离根）/ 幂等 / 无 base-panel 回退 / 已渲染跳过；
2. 全量 jest 基线 diff 空；
3. 4 组件批次 + multi-dim-score + visual-diff + 截图目检（验收门 4/4）。

## 6 续接：双份 tabs 收口（`9d7726e`，2026-11-10 用户截图 7b4ae1d8 实锤）

游离根修好后显形的相邻缺陷：header-right 已承载 label 契约（HeaderSection 子组件形态）时，
`templateRendersTabs` 只认 v-for 绑定判「模板无 tab」⇒ 骨架自愈仍注入内容区 tab 栏
⇒ header 胶囊 + 内容区 tabs 双份（日志 `04:42:12.329/.382` 自愈×2 实证）。

**修法**：新增 `headerChannelOccupied` 前置闸——header 专属插槽（header-right/title-left/
title-right）非空（剔注释后有真实元素，子组件标签也算承载）⇒ 跳过注入。判据纯结构零硬编码；
空插槽/无插槽行为不变（向后兼容）。spec 7/7（用例①改空插槽形态保留落点验证 + ⑥阳性/⑦阴性）；
全量 jest 基线新增失败 0。
