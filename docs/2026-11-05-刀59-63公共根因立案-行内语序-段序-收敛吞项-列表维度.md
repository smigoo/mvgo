## §1 Phase 2 根因（证据链摘要）

### 刀60 · 行内语序 + pad 判据（四案公共，最高优先）

- 0ddd1708 `StatsSection.vue`：`runs=["8"(fs24),"总设备"(fs14)]` 颠倒 + `pad:86`（卡宽 134px，内容起点 64%）+ `gap:0`。
- 根因：cardTruth 的 tb 排序 **y-then-x**——数值 24px 与 label 14px 垂直居中基线不同 → 数值 bbox y 略小 → 排前 ⇒ pad 取数值.x−卡.x=86、语序颠倒、gap 失真，**一个根因三症状**。
- 判据假设：同行成员（y 差 < 行高容差）应聚类后**按 x 排序**；pad/gap 取 x 序首成员。可复用同文件既有 `clusterByTolerance/KV_TOL`（region-partitioner 已反向 import，单一事实源）。
- LLM 线同症状另案（刀56 扩 C）。

### 刀61 · 段级装配序（c0d64b92 头部掉底）

- planner `effectiveSections` 产出序 = `801:3(图片+属性) → 36:1724(标题) → 36:1708(描述)`，index 骨架照抄 ⇒ 标题段渲染在页中（渲染图 #4 底部大字 GD-Robot-04）。
- 根因：段产出按切分遍历序，**未按 bbox y 排序**；文本级 sortByVisualOrder 不覆盖段级。
- 判据假设：effectiveSections 落盘前按段 bbox y 升序稳定排序（缺 bbox 的段保持原序 fail-open）；计数行 `sectionOrderFixed=N`（0 也打）。

### 刀62 · 并列非重复项收敛吞并（0ddd1708 图例丢「离线」）

- `ContentFooter.vue` 单模板单值：`const text="运行中"` + 1 dot——真值 2 组 dot+text（绿/运行中、橙/离线）被收敛成单项。
- 根因：折叠器/叶判据「重复收敛」无**文本一致性**前置——文本不同的并列项（dot 色也不同）被误收敛单值。
- 判据假设：收敛仅当成员**结构+文本模板（占位符化）一致**才 v-for 收敛；否则逐项渲染。计数行 `convergenceSkipped=N`。
- 阳性：43:4869 回放产出 2 图例项（双 dot 双色双文本）。

### 刀63 · fg-list 接管维度（0ddd1708 表格样式，裁决：不走 a-table）

- 产物有表头/行/斑马类骨架但视觉与 UI 不符：表头底色、斑马交替、外框形态、列宽分配的真值维度覆盖不全（figma.json 斑马浅蓝 `#e2ecfe/#d6e5ff` 各 16 处真值在场）。
- 修法：接管渲染器补真值维度：表头 fills、行斑马（行 fills 差集推导交替色）、外框、列宽比例。
- 用户裁决：**确定性接管补维度，不引入 antd a-table**（避免运行时依赖与主题漂移）。

### 刀59 · ce80876f（真值双落 / 样式裸奔 / 渐变上提）

1. **真值双落**：同一份「面板底+圆角+内发光」真值写两处（根 inline + 网格类），网格固定列宽不铺满 → 两层背景框错位。判据假设：同一 section 子树内「background+borderRadius+boxShadow 同值组合」唯一落点（根优先），子级重复落 WARN/剥离。
